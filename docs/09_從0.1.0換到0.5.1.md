# iPLoT：從 0.1.0 換到 0.6.0

給已經在用 iPLoT 0.1.0、要換成 0.6.0 並開始用行事曆的人。只在 macOS 上用過。畫面上的字（按鈕、選單、訊息）用「」框起來，照 iPLoT 程式裡的字寫。

## 1. 開始之前

1. 按 ⌘＋空白鍵，打「終端機」，按 Enter。
2. 打 `python3 --version`，按 Enter。
3. 要看到 Python 3.10 以上（例如「Python 3.14.0」）。不到 3.10 就先停下來，截圖給我。
4. 舊的 0.1.0 資料夾先留著，不要刪、不要改名。

## 2. 下載與解開

1. 在 Safari 打開 <https://william10310406.github.io/iplot-workshop/>。
2. 按「iPLoT 0.6.0」底下的「下載 iPLoT-v0.6.0.zip」。這一頁只有這一個下載：模組不再列在這裡，裝好之後在 iPLoT 裡按「工作坊」。
3. 打開「下載項目」。Safari 通常會自動解開，直接出現資料夾「iPLoT-v0.6.0」；只看到 `iPLoT-v0.6.0.zip` 的話，雙擊它。
4. 在 Finder 按 ⇧⌘H 打開家目錄，把「iPLoT-v0.6.0」資料夾拖進去。
5. 把它改名成「iPLoT-0.6.0」。不要跟舊的資料夾同名，也不要留在「下載項目」裡。

0.6.0 起包裡多一個「回報與討論」（出錯時按錯誤旁邊的「回報這個問題」，見 `docs/08_操作說明-0.6.0.md` 第 10 節）。

## 3. 第一次打開

打開 `~/iPLoT-0.6.0`，雙擊 `iPLoT.command`。macOS 會擋下來，照自己的 macOS 版本做（蘋果選單 →「關於這台 Mac」看版本）。畫面可能跟這裡寫的不完全一樣，請截圖給我。

**macOS 15 以上**

1. 跳出的對話框只有「完成」和「丟到垃圾桶」：按「完成」。
2. 蘋果選單 →「系統設定」→「隱私權與安全性」。
3. 往下捲到「安全性」，找到說「iPLoT.command」被阻擋的那一句，按旁邊的「強制打開」。
4. 跳出的對話框再按一次「強制打開」，輸入密碼或用 Touch ID。
5. 再雙擊一次 `iPLoT.command`。

**macOS 14 以下**

1. 在 `iPLoT.command` 上按右鍵（或 Control＋按），選「打開」。
2. 對話框裡再按「打開」。

**另一條路（任何版本都可以）**：在終端機打下面這一行，按 Enter，之後直接雙擊 `iPLoT.command`。

```
xattr -dr com.apple.quarantine ~/iPLoT-0.6.0
```

## 4. 第一次啟動

1. 雙擊之後開出一個終端機視窗，寫著「第一次啟動：正在安裝介面（需要網路，約 40 MB）…」。要有網路，大約兩分鐘。
2. 等到「安裝完成，重新啟動中…」，接著出現標題是「iPLoT v0.6.0」的面板。
3. 這段期間 macOS 可能跳出「『終端機』想要取用……」的權限框，按「允許」或「不允許」都可以，iPLoT 照常開。
4. 那個終端機視窗要留著（可以縮到 Dock），關掉它 iPLoT 也會關掉。之後再雙擊 `iPLoT.command` 就直接開面板，不再安裝。

## 5. 搬自己的模組

0.1.0 原本就附的四個不用搬：「打開核心原始碼」「重新啟動」「開Terminal」「開工」。新的資料夾裡已經有新版的。

1. 打開舊的 iPLoT 資料夾裡的 `modules/`，選起自己做的那幾個資料夾，按 ⌘C。
2. 打開 `~/iPLoT-0.6.0/modules/`，按 ⌘V。名字跟裡面已經有的一樣時，先停下來問我。
3. 舊的 `config.py` 改過的話：兩份都用「文字編輯」打開，把舊的那份 `ROOTS`、`EDITOR`、`HISTORY_KEEP` 改過的值抄到新的那份同一行。新的那份最後三行（`UPDATE_URL`、`WORKSHOP_URL` 和上面的說明）留著，不要整個蓋掉。
4. 在面板雙擊「重新啟動」，自己的模組出現在「這一層」。

放在舊 iPLoT 資料夾旁邊的模組（面板上「上一層」那一組）：新的也放在家目錄，就照樣看得到，不用搬。

自己的模組要注意的兩件事：

- 用到 `app.window`、或自己用 tkinter 開視窗的，在新版不能用，要改。
- `input()` 的對話框按「取消」，那個模組會停下來（面板顯示「在提問時按了取消」）；`exit()` 不再算出錯。

## 6. 把行事曆更新到 0.1.1

0.6.0 的包裡已經是行事曆 0.1.1，這一步不用做。

## 7. 把行事曆放到 Dock

1. 在面板雙擊「互通」（🔗），開出「互通」的視窗。
2. 在「捷徑」那一段按「在 Finder 中顯示」。Finder 打開，「捷徑」資料夾是選起來的；雙擊它打開。
3. 把裡面的「行事曆」拖到 Dock 上，放在分隔線左邊。
4. 之後點 Dock 上的「行事曆」就會打開。先跳出一個小視窗說「打開行事曆」，3 秒後自己關掉；行事曆已經開著時，就把它叫到最前面。

## 8. 行事曆怎麼用

- **寫一天**：打開是這個月的月曆，點一天進去。四個欄位：「行程」、心情（點 😄 🙂 😐 😟 😢 其中一個，旁邊「一句話」寫一行）、「看到了什麼」、「做了什麼」。打完停一秒就自動存，狀態列出現「已存」。關視窗前看到「已存」再關。
- **照片**：把照片從 Finder 拖到圖片列（虛線框），或按「加圖片」。一張 30 MB 以內；iPhone 的 HEIC 會另外轉一張 JPG。
- **看網頁**：按「看網頁」，用瀏覽器看正在看的那一天（月、年）。
- **資料存在哪裡**：`~/Documents/行事曆`，一天一個資料夾，裡面是一般的文字檔和照片。這台 Mac 開了 iCloud 的「桌面與文件」，這些就會跟著上 iCloud。
- **公開與發佈**：每一天預設不公開。勾「公開（按「發佈」時放上網路）」，再按「發佈」→「產生」，會做出一個 `發佈/` 資料夾，裡面只有公開的日子。這一版不會幫忙上傳；把 `發佈/` 放上網路之後，知道網址的人都看得到。

## 9. 壞了怎麼辦

把這些傳給我：

1. 出問題的那個視窗的截圖（面板、小視窗或行事曆）。訊息區有出錯那一行的話，先按「詳細」展開再截。截圖：⇧⌘4，再按空白鍵，點那個視窗。
2. 雙擊 `iPLoT.command` 時跟著開的那個終端機視窗的截圖。
3. macOS 跳出的對話框的截圖。
4. `~/iPLoT-0.6.0/logs/iplot.log`（訊息區寫「核心錯誤：……詳細內容在 logs/iplot.log」時才有這個檔）。
5. 面板的標題（例如「iPLoT v0.6.0」）、macOS 的版本、`python3 --version` 的結果。
6. 做了什麼之後出的事，再做一次會不會一樣。
