# iPLoT 0.6.0 操作說明

給從沒用過 iPLoT 的人，照著做就會用。只在 macOS 上用過（開發用的是 macOS 26.5、python.org 的 Python 3.14）；Windows 未經實機驗證，這一版的 Linux 沒有網頁面板。

畫面上的字（按鈕、選單、訊息）照程式裡的字寫，用「」框起來。兩種標記：

- **（推測，未親眼看）**：macOS 自己的畫面，是根據系統工具的結果與 macOS 的已知行為推出來的，沒有人在那個畫面上親眼看過。
- **（未核）**：不是 iPLoT 的程式畫出來的（例如安裝 Python 的畫面），字沒有對過。

## 1. 安裝

### 1.1 從沒裝過

**第 1 步：看看有沒有夠新的 Python。** 按 ⌘＋空白鍵，打「終端機」，按 Enter，開出一個終端機視窗。打：

```
python3 --version
```

按 Enter。

- 顯示「Python 3.10」以上（例如「Python 3.14.0」）：跳到第 3 步。
- 顯示「Python 3.9.6」，或跳出一個對話框問要不要安裝「命令列開發者工具」（推測，未親眼看）：那是 macOS 內建的舊版，iPLoT 用不了。對話框按取消，做第 2 步。

**第 2 步：裝 Python。** 打開 Safari，到 `https://www.python.org/downloads/`，按最上面那顆下載鈕（例如「Download Python 3.14.0」，未核）。下載好的 `.pkg` 在「下載項目」裡，雙擊它，照安裝程式一路按「繼續」「同意」「安裝」，輸入這台 Mac 的密碼（未核）。裝完會跳出一個 Finder 視窗，裡面有「Install Certificates.command」等檔，iPLoT 不需要它們，關掉就好。把剛才的終端機視窗關掉、再開一個新的，打 `python3 --version`，要看到 3.10 以上。

**第 3 步：下載 iPLoT。** 在 Safari 打開 `https://william10310406.github.io/iplot-workshop/`。這一頁的標題是「iPLoT 工作坊」，下面寫著「iPLoT 0.6.0」，按「下載 iPLoT-v0.6.0.zip」。這一頁只有這一個下載：模組在 iPLoT 裡按「工作坊」裝。

**第 4 步：解開。** Safari 預設會把 zip 自動解開，「下載項目」裡會直接出現一個資料夾「iPLoT-v0.6.0」（推測，未親眼看）。沒有自動解開的話，雙擊 `iPLoT-v0.6.0.zip`。

**第 5 步：搬到家目錄。** 不要留在「下載項目」裡（iPLoT 會掃描它所在資料夾的上一層，留在「下載項目」就會把整個「下載項目」掃一遍）。在 Finder 按 ⇧⌘H 打開自己的家目錄，把「iPLoT-v0.6.0」資料夾拖進去，改名成「iPLoT」（不改也可以）。

**第 6 步：雙擊 `iPLoT.command`，過 macOS 的那一關。** 打開 `~/iPLoT`，雙擊 `iPLoT.command`。從網路下載的檔沒有 Apple 的簽章，macOS 會擋下來（開發用的 Mac 上系統工具的判定是「rejected」，見 `docs/plans/2026-10-15-0.5.1-版本報告.md` 第 3.2 節（開發紀錄，只在 git repo 裡；下載的包裡沒有 `docs/plans/`））。

- macOS 15（Sequoia）以後（推測，未親眼看）：跳出「無法打開『iPLoT.command』」或「Apple 無法驗證……」一類的對話框，只有「完成」和「丟到垃圾桶」。按「完成」。打開蘋果選單 → 「系統設定」→「隱私權與安全性」，往下捲到「安全性」那一段，會有一句說「iPLoT.command」已被阻擋，旁邊一顆「強制打開」（按鈕的字依系統版本可能不同，未核）。按它，再在跳出的對話框按一次「強制打開」，輸入密碼或用 Touch ID。之後再雙擊 `iPLoT.command` 就會打開。
- macOS 14 以前（推測，未親眼看）：不要直接雙擊；在 `iPLoT.command` 上按右鍵（或 Control＋按），選「打開」，對話框裡再按「打開」。
- 不想走上面那幾步：在終端機打下面這一行（把整個資料夾的「從網路下載」標記拿掉），之後直接雙擊就好：

  ```
  xattr -dr com.apple.quarantine ~/iPLoT
  ```

**第 7 步：第一次啟動會自動安裝介面，要有網路。** 雙擊之後會開出一個終端機視窗，顯示「第一次啟動：正在安裝介面（需要網路，約 40 MB）…」和一行行安裝的進度。在開發用的 Mac 上花了 1 分 46 秒（看網路速度）。裝完顯示「安裝完成，重新啟動中…」。

這段期間或之後，macOS 可能跳出「『終端機』想要取用『桌面』（或『文件』『下載項目』）檔案夾中的檔案」一類的對話框（推測，未親眼看；iPLoT 會掃描家目錄底下的資料夾找模組）。按「允許」或「不允許」都可以：不允許只是那個資料夾不掃，iPLoT 照常開。

**第 8 步：面板出現。** 一個標題是「iPLoT v0.6.0」的視窗。上面一列是「iPLoT」，中間一組組的圖示：「這一層」是 iPLoT 資料夾裡 `modules/` 的十一個模組（主控面板、互通、作業系統、回報與討論、工作坊、打開核心原始碼、更新、行事曆、重新啟動、開Terminal、開工），「上一層」是 iPLoT 所在的資料夾（家目錄）裡的模組，通常是空的，寫「尚無模組，按 ＋ 新增」。下面是狀態列與訊息區，訊息區第一行是「已掃描 …，找到 N 個模組」。

跟著開的那個終端機視窗要留著（可以縮到 Dock）：關掉它會把 iPLoT 一起關掉（推測，未親眼看；關的時候終端機會先問要不要結束執行中的程式）。之後每次雙擊 `iPLoT.command` 都直接開面板，不再安裝、不用網路。

**沒有網路、或安裝失敗**：終端機說「介面安裝失敗：…安裝需要網路。再試一次：重新啟動 iPLoT。現在先改用備用面板」，接著開一個樣子比較簡單的備用面板（一欄文字按鈕）。有網路之後關掉再雙擊 `iPLoT.command`，會再裝一次。

**Python 太舊**：終端機只有一句「iPLoT 需要 Python 3.10 以上（目前是 3.9.6）。請安裝 python.org 的版本。」，面板不會出現。回到第 2 步。

### 1.2 已經有舊版

先看面板的標題是哪一版（例如「iPLoT v0.5.0」）。

**0.5.x：先到工作坊做兩件事，再按「更新」。**「更新」跳出來的說明就是這一段：

這一版在錯誤訊息旁邊多一顆「回報這個問題」：按下去會整理好版本與錯誤，先把路徑、使用者名稱、學號遮掉給你看、讓你改，再用瀏覽器開到 iPLoT 的 GitHub 討論區，登入後按送出才會公開；面板上也多一格「回報與討論」，可以提建議、問問題、看大家在討論什麼。已經在用的人請先按「取消」，照這個順序做：①先到「工作坊」，「互通」按「覆蓋」或「更新」、「回報與討論」按「安裝」——「更新」不碰 modules/，新的互通 0.2.0 才認得 iPLoT 0.6.0（它在 0.5 上也能跑），沒先換的話，按完「更新」之後捷徑、面板外的執行、行事曆都會停下來，說「互通 0.1.0 支援 iPLoT 0.5」；②換好之後再回來按「更新」，這一次按「確定」，更新完執行「重新啟動」。工作坊裡找不到「回報與討論」的（還沒照 0.5.2 的說明換工作坊；那份舊清單上的「互通」是 0.1.0，覆蓋了也沒用），就回來按「更新」、這一次直接按「確定」，再從 .backup/download-0.6.0.zip 解開（.backup 以 . 開頭：在終端機進到 iPLoT 資料夾打 open .backup），把裡面 iPLoT-v0.6.0/modules 的「回報與討論」「互通」「工作坊」三個資料夾整個換進自己的 modules/，再打開 config.py，把 WORKSHOP_URL 那一行換成 WORKSHOP_URL = "https://william10310406.github.io/iplot-modules/index.json"，最後執行「重新啟動」，在面板雙擊一次「互通」把捷徑重新做好。新下載的 iPLoT 不用做。

第 1 到 5 步給已經照 0.5.2 的說明換過工作坊的人（下載的就是 0.5.2 的也算；工作坊裡找得到「回報與討論」）；其他人直接做第 6 步。

1. 在面板雙擊「工作坊」（🧰）：「互通」按「覆蓋」（從工作坊裝過的是「更新」，還沒裝過的是「安裝」）、「回報與討論」按「安裝」，關掉清單。
2. 雙擊一個用到互通的捷徑或「行事曆」：照常開（這時候核心還是 0.5.2）。
3. 雙擊「更新」（⬆️）。跳出「有新版 0.6.0（現在是 0.5.2）：」加上這一版的說明，最後一句「要更新嗎？」。這一次按「確定」。訊息區出現「已更新到 0.6.0，執行「重新啟動」就會用新版。舊版備份在 .backup/0.5.2-<日期時間>/」。
4. 雙擊「重新啟動」。視窗的標題變成「iPLoT v0.6.0」。第一次執行「回報與討論」或互通時會先問一次（它們是從工作坊裝進來的），按「確定」。
5. 隨便讓一個模組出錯（例如在一個新模組寫 `1/0`），錯誤那一列有「回報這個問題」。
6. 工作坊裡找不到「回報與討論」的，照說明最後那幾句做：回來按「更新」、這一次直接按「確定」，再從 `.backup/download-0.6.0.zip` 換：在終端機進到 iPLoT 資料夾，打 `open .backup`，雙擊 `download-0.6.0.zip` 解開；把 iPLoT 資料夾裡的 `modules/互通`、`modules/工作坊` 丟進垃圾桶，再把解開的 `iPLoT-v0.6.0/modules` 裡的「回報與討論」「互通」「工作坊」三個資料夾拖進 `modules/`；用文字編輯器打開 iPLoT 資料夾裡的 `config.py`，把 `WORKSHOP_URL` 那一行換成 `WORKSHOP_URL = "https://william10310406.github.io/iplot-modules/index.json"`，存檔；雙擊「重新啟動」；最後在面板雙擊一次「互通」（🔗）：丟掉的 `modules/互通` 裡有捷徑（`捷徑/`）和記下的 Python，雙擊一次就重新記下、把捷徑重新做好（第 3 節）。Dock 上拖過去的「捷徑」資料夾或某一個 `.app` 指的還是丟掉的那一份（推測，未親眼看）：從 Dock 拿掉，按「互通」視窗裡的「在 Finder 中顯示」再拖一次。不換工作坊和 `WORKSHOP_URL` 的話，工作坊看到的一直是凍結的舊清單，新的模組不會出現。

「開工」「打開核心原始碼」在清單上會是「可更新」或「版本未知」，要不要換新版都可以（新版多了「互通」那一小段）。`README.md`、`docs/`、`iPLoT.command` 這些檔「更新」不會換，舊的留著；看這一份說明就好。

**0.4.0 以前：重新下載。** 那幾版沒有「更新」這個模組。照 1.1 的第 3 步到第 8 步下載一份新的，放在新的位置（例如 `~/iPLoT-0.6.0`）。自己做的模組，從舊的 `modules/` 把那幾個資料夾複製到新的 `modules/`；`config.py` 改過的話，對照著改新的那一份（不要整個蓋掉，新的多了兩行網址）。舊的資料夾確定不要了再丟掉。

## 2. 面板的基本操作

- **單擊**一格：選起來，狀態列顯示它的名稱與說明。沒選的時候狀態列是「單擊選一個模組看它的說明；雙擊執行。」
- **雙擊**一格：執行它。選起來之後按 Enter 也一樣。跑得比較久時，狀態列右邊顯示「執行中：<名稱>…」；跑完訊息區一行「<名稱> 完成（x 秒）」。
- **出錯**：訊息區一行「模組『<名稱>』第 N 行出錯：…」，後面幾顆按鈕：「打開檔案」用文字編輯器打開那個檔、跳到那一行；「詳細」展開完整的錯誤內容（再按一次「收起」）；「回報這個問題」把這個錯誤整理成一篇貼文、先給你看，再用瀏覽器開到 iPLoT 的 GitHub 討論區（`modules/` 裡有「回報與討論」才有這一顆，按一次就變灰；見第 10 節）。
- **右鍵**一格，選單是：「執行」、「進入下一層」（只有底下還有模組的那一格才有）、「打開程式碼」、「在資料夾中顯示」、「在終端機打開」、「在這裡新增下一層模組…」。
- **＋**：每一組最後一格虛線的「新模組」。按下去問「新模組的名稱」，打好按「確定」：在那一組的資料夾裡建一個同名的資料夾與 `iplot.py`，並用文字編輯器打開它。注意「上一層」那一組的 ＋ 會建在 iPLoT 所在的資料夾（家目錄）裡；要建在 iPLoT 裡就用「這一層」的 ＋。名稱不行時會說「名稱不能是空白、以 . 開頭……」那一句。
- **▸ 與下一層**：一格的右上角有「▸」，表示它底下還有模組。按「▸」（或右鍵「進入下一層」）進去，上面那一列變成「iPLoT ▸ <名稱>」；按前面的「iPLoT」回到最上層。
- **模組問問題**（模組裡寫了 `input()`）：面板中間跳出一個對話框，打好按「確定」；按「取消」那個模組會以「在提問時按了取消」結束。

## 3. 互通：不開面板也能打開模組

新下載的 0.6.0 已經帶著「互通」。從 0.5.0 更新上來的，先照 1.2 的第 1 步（工作坊裡找不到「回報與討論」的是第 6 步）裝。

**做捷徑。** 在面板雙擊「互通」（🔗）。它會記下現在用的 Python、替每個模組做一個捷徑，然後開一個標題是「互通」的視窗：

- 最上面一句「N 個模組能在面板外打開（捷徑、指令）；其中 M 個能直接 python3 iplot.py。」
- 「捷徑」：列出做好的捷徑，下面一顆「在 Finder 中顯示」，按下去打開放捷徑的資料夾（`iPLoT/modules/互通/捷徑/`）。每個模組一個 `.app`，名字是模組的名稱，下一層的叫「父 › 子」；「作業系統」沒有捷徑。
- 「指令」：一行可以在終端機用的指令，「複製」把它複製起來（成功時旁邊寫「已複製」）。
- 「可以加上那一小段的模組」（有才出現）、「沒加那一小段的模組」、「上一次同步的問題」、「記下的 Python」、最下面「再同步一次」（按了顯示「同步中…」，好了是「同步好了」）。

之後每次從捷徑打開任何模組、或在面板按「互通」，捷徑都會跟著模組的增減、改名重新整理一次。

**拖到 Dock。** 按「在 Finder 中顯示」，把整個「捷徑」資料夾拖到 Dock 右邊（垃圾桶旁邊那一區），點它就是一排模組；點一個就打開那個模組。也可以只拖某一個 `.app`（例如「行事曆.app」）到 Dock。

**Spotlight。** 按 ⌘＋空白鍵，打模組的名稱（例如「開工」），按 Enter。

**從捷徑打開時看到的小視窗。** 模組沒說話就安安靜靜跑完、什麼都不出現。模組有話要說、出錯、問問題、或跑超過 1 秒，才出現一個小視窗：

- 跑超過 1 秒：「執行中：<名稱>…」和「停止」（按了就結束那一次執行，面板不受影響）。
- 跑完：「完成（x 秒），3 秒後關閉」倒數；在小視窗裡按任何一下就停下來，換成「關閉」。
- 出錯：「出錯了」和「關閉」，錯誤那一行有「打開檔案」「詳細」。
- 跑完、小視窗還在時，「關閉」旁邊多一顆回去鈕：有「行事曆」就是「行事曆」（回到行事曆），沒有就是「主控面板」（回到面板）。
- 第一次從捷徑打開時，macOS 可能問「Python」要不要取用「文件」「桌面」「下載項目」（推測，未親眼看）：iPLoT 放在那些資料夾裡時一定要允許；放在 `~/iPLoT` 時是因為會掃描家目錄底下的資料夾，按「不允許」也照常能用。

**「加上」是什麼、什麼時候要按。** 「互通」的那一小段是加在模組 `iplot.py` 開頭的 22 行，兩頭是 `# ── 互通 ──`。有了它，在終端機進到那個模組的資料夾、打 `python3 iplot.py`，也會用小視窗跑（跟從捷徑打開一樣）。沒有它，從捷徑與指令照樣打得開，只是直接 `python3 iplot.py` 時是一般的 Python 腳本。

- 隨附的模組大多已經帶著（作業系統、工作坊、更新除外）。
- 用 ＋ 新建的模組**不**帶。要直接 `python3 iplot.py`，在「互通」視窗的「可以加上那一小段的模組」那一區會看到它（名稱與 `iplot.py` 的完整路徑），按「加上（N 個檔）」。之後那一區下面會說「加上了 N 個：……」。每個檔改之前先存一份到它自己的 `.history/`。
- 只會加在 iPLoT 的 `modules/` 裡的模組；iPLoT 旁邊（上一層）的不改。不要了就把那兩行 `# ── 互通 ──` 之間整段刪掉。
- 只想從面板或捷徑打開的話，不用按。

## 4. 主控面板

「主控面板」（🎛️）打開 iPLoT 的面板；面板已經開著就叫到最前面，不會開第二個。

- 在面板裡雙擊它：面板跑到最前面，訊息區「主控面板已經開著」。
- 從捷徑、Spotlight、Dock 打開，或在別的模組裡寫 `app.run("主控面板")`：面板沒開就開一個（小視窗說「打開主控面板」，3 秒後關）；開著就叫到最前面（「主控面板已經開著，叫到最前面了」）。叫不到最前面時說「主控面板已經開著，但沒辦法把它叫到最前面」，到 Dock 點它。
- 剛開的面板偶爾會在別的視窗後面，到 Dock 點一下 Python 的圖示（已知問題，見 `docs/plans/2026-10-15-0.5.1-版本報告.md` 第 5 節（開發紀錄，只在 git repo 裡；下載的包裡沒有 `docs/plans/`））。

## 5. 行事曆

在面板雙擊「行事曆」（月曆圖示）：訊息區「打開行事曆」，另一個標題是「行事曆」的視窗打開，面板照常可以按別的模組。行事曆要用「互通」；沒有互通時訊息區說「行事曆要用「互通」另開視窗：到工作坊裝「互通」」。已經開著再雙擊一次：「行事曆已經開著」，那個視窗跑到最前面；叫不到最前面時說「行事曆已經開著（在 Dock 上找月曆的圖示）」。開著的行事曆在 Dock 上是月曆的圖示，名字是「Python」。

視窗上面兩列：

- 第一列是模組列（見 5.8），最右邊「圖示面板」。
- 第二列：「年」「月」「日」三個檢視、「‹」「›」（上一個、下一個）、中間是現在看的年月日、「今天」、右邊「看網頁」「發佈」「⚙」。
- 最下面一行是狀態列，存好、出錯都在這裡說。

**月檢視**（打開時的樣子）：這個月的月曆，星期日在最左邊，今天的日期有紅底。有寫東西的日子底色不同，格子裡是表情、🖼（有照片）、🌐（公開）和那一天的第一行。點一天就到那一天。**年檢視**：12 個小月曆，有寫東西的日子上色、顯示表情或一個點，點一天就到那一天。

### 5.1 寫四個欄位

點一天進到日檢視：上面是日期，接著是五個表情和一個「一句話」的輸入框，再下面三個框：「行程」「看到了什麼」「做了什麼」。

打字之後，離開那個框、或停下來 1 秒，就自動存，狀態列出現「已存」。換一天、換檢視之前也會先存。關視窗前最後一秒打的字可能來不及存：打完停一下，看到「已存」再關。

存不進去時（例如資料夾在拔掉的隨身碟上），狀態列說「存不進去：<原因>。字還在，等一下會再試」，字留在框裡，修好之後下一次會存進去；這時換檢視、換一天都會先停在這一天，不會把字丟掉。

用文字編輯器把某個檔存成不是 UTF-8 的格式，那個欄位會顯示「讀不到這個檔（不是 UTF-8），沒有覆寫它：<路徑>」，不能在頁面上改，檔案也不會被蓋掉。

### 5.2 表情

日檢視的五個表情：😄 🙂 😐 😟 😢。點一個就選它並馬上存；再點一次同一個就取消。旁邊的「一句話」是那天心情的一句話（只有一行）。

### 5.3 照片

- 按圖片列裡的「加圖片」選照片，或把照片從 Finder 拖到圖片列（虛線框，滑鼠停上去寫「把照片拖進來」）。一次可以多張，一張 30 MB 以內。狀態列先說「加入中：<檔名>」，好了是「已加入：<檔名>」，圖片列出現縮圖。
- iPhone 的 HEIC 照片：原檔留著，另外轉一張同名的 JPG（只在 macOS）。轉不成時說「<檔名>：轉不成 JPG，Chrome 看不到」。
- 不收的：「<檔名>：太大（超過 30 MB）」、「<檔名>：不是圖片」。
- 縮圖右上角的「×」：把那張照片搬到垃圾桶（拿掉的是 HEIC 轉出來的 JPG 時，原本的 HEIC 一起），可以從垃圾桶拿回來。

### 5.4 看網頁

寫的東西同時存成網頁。按「看網頁」，用預設的瀏覽器打開正在看的那一天（在月檢視是那個月、在年檢視是那一年）的網頁。⚙ 裡的「打開綜合網頁」是最近 30 天，與每一年、每個月的入口。網頁就是資料夾裡的 `index.html`，在 Finder 裡雙擊也能看；沒有用到網路，整個資料夾搬到別處也能看。

### 5.5 公開與發佈

每一天預設不公開。日檢視最下面勾「公開（按「發佈」時放上網路）」，狀態列說「這一天會放上網路（按「發佈」才產生）」；取消勾選是「這一天不公開」。

按「發佈」：先問「要放上網路的有 N 天（只有打開『公開』的日子）。產生發佈用的資料夾？」，按「產生」。做好之後說「放了 N 天到：<資料夾>/發佈。上傳方式還沒設定：把『發佈』裡的東西放到網頁空間」，處理不了的照片會一張一句列在下面，並在 Finder 打開 `發佈/` 這個資料夾。沒有打開「公開」的日子、也從來沒發佈過時，只說「還沒有打開「公開」的日子」，什麼都不產生。

`發佈/` 裡只有打開「公開」的日子：網頁、照片縮小過、拿掉了拍攝地點等資料，網頁請搜尋引擎不要收；文字原檔、沒公開的日子、HEIC 原檔都不在裡面。取消公開的日子，下一次「發佈」時會從 `發佈/` 消失。自己放進 `發佈/` 的別的檔，下一次「發佈」也會被刪掉。

把最後一個公開的日子也取消之後再按「發佈」：上一次產生的 `發佈/` 整個拿掉，狀態列說「沒有公開的日子了，已經拿掉 發佈/」（行事曆 0.1.1 起；0.1.0 會把 `發佈/` 留著，要自己丟進垃圾桶）。之後有公開的日子再按「發佈」，會重新產生。

**這一版不會幫忙上傳。** 要放上網路，就把 `發佈/` 裡的東西放到網頁空間。放上去之後，知道網址的人都看得到，沒有密碼。

### 5.6 換資料夾

按「⚙」：第一行「資料夾：<路徑>」，下面「換資料夾」「打開資料夾」「打開綜合網頁」「重建全部網頁」，最下面「關閉」。

「換資料夾」：會先跳出一個 iPLoT 的小視窗，接著出現系統的選擇視窗，選一個資料夾。行事曆從此讀寫那個資料夾；原本的資料不會搬，還在原處，換回來就都在。「打開資料夾」在 Finder 打開現在的資料夾。

### 5.7 重建全部網頁

直接用文字編輯器改了 `.txt` 之後，網頁不會自己跟著變。按「⚙」→「重建全部網頁」，狀態列說「重建了 N 頁」。

### 5.8 模組列

第一列是 iPLoT 的每一個模組（作業系統、行事曆自己、主控面板除外），每顆是模組的圖示或名稱的第一個字，滑鼠停上去顯示名稱。點一顆，那個模組就在它自己的小視窗裡跑（狀態列說「打開「<名稱>」」），行事曆照常可以用。最右邊的「圖示面板」打開 iPLoT 的面板（有「主控面板」這個模組才出現）。之後才裝的模組，切到別的視窗再回來，模組列就會看到。

### 5.9 小視窗的「行事曆」鈕

從捷徑、Dock 或行事曆的模組列打開別的模組，跑完、小視窗還在時，底下多一顆「行事曆」：按下去回到行事曆（已經開著就叫到最前面，不會開第二個），小視窗關掉。

### 5.10 資料存在哪、長什麼樣

預設在 `~/Documents/行事曆`（家目錄的「文件」裡），第一次存東西時才建。一天一個資料夾：

```
~/Documents/行事曆/

  2026/
    index.html               這一年
    10/
      index.html             這個月
      14/

        公開                  空檔案；有就是公開
        IMG_0001.HEIC  IMG_0001.jpg            照片
```

## 6. 更新、工作坊、回到舊版、整個移除

**更新**：雙擊「更新」。有新版會問「有新版 X（現在是 Y）：…要更新嗎？」，按「確定」之後雙擊「重新啟動」；已經是最新會說「已是最新（0.6.0）」。換掉的四樣先備份在 iPLoT 資料夾的 `.backup/` 裡。換完、還沒重新啟動又按一次，說「已經換成 X 了，執行「重新啟動」就會用新版」。新版要的套件不一樣時，下一次啟動終端機會說「介面要用的套件換了版本，正在重新安裝（需要網路）…」。

**工作坊**：雙擊「工作坊」，開一個清單。最上面一行是「這裡的模組是大家上傳的，沒有人審查。裝進來的模組第一次執行前 iPLoT 會先問；按確定之前，在面板上右鍵「打開程式碼」看一眼。」每一列：圖示、名稱、名稱底下一行「上傳者：@<帳號>」、說明、版本、狀態、一顆按鈕；被研究助理標了的那一列多一行紅字「⚠ …」。

| 狀態 | 按鈕 |
|---|---|
| 未安裝 | 「安裝」 |
| 已安裝 | 沒有 |
| 可更新 | 「更新」 |
| 已修改（裝過之後改過） | 「覆蓋」 |
| 版本未知（自己做的同名模組，或隨附的模組） | 「覆蓋」 |
| 隨附模組（作業系統、更新、工作坊） | 沒有 |

按了「安裝」「更新」「覆蓋」，那一列說「無法安裝：下載的檔案跟清單對不上。清單可能剛更新過，關掉工作坊再開一次；再不行就是檔案有問題」：照它說的，關掉清單的視窗再雙擊一次「工作坊」。「覆蓋」會先變成「確定覆蓋」「取消」，再按一次「確定覆蓋」才做；覆蓋之前，舊的資料夾整個存進那個模組的 `.history/`。關掉清單的視窗，新裝的模組出現在面板上。裝進來的模組第一次執行前會先問「『<名稱>』是從外面裝進來的，第一次執行前確認：要執行嗎？」。工作坊沒有「移除」：不要的模組，把它的資料夾從 `modules/` 丟進垃圾桶。

**回到舊版**（手動）：

1. 關掉 iPLoT。
2. 在終端機進到 iPLoT 資料夾，打 `open .backup`，用 Finder 打開備份資料夾（以 `.` 開頭，Finder 平常不顯示），找到要回去的那一份（例如 `0.5.0-20261015-093000`）。
3. 把 iPLoT 資料夾裡現在的 `core`、`ui`、`main.py`、`requirements` 丟進垃圾桶，再把備份裡的這四樣複製過來。
4. 雙擊 `iPLoT.command`。

`config.py`、`modules/` 不用動。

**整個移除**：

1. 關掉 iPLoT、行事曆和所有小視窗。
2. 把整個 iPLoT 資料夾丟進垃圾桶（裡面的介面套件 `lib/`、備份 `.backup/`、互通的捷徑都在裡面）。
3. Dock 上拖過去的捷徑：拖出 Dock 移除。
4. 行事曆的資料在 iPLoT 外面（`~/Documents/行事曆`，或換過的資料夾），要不要刪自己決定。
5. 「系統設定 → 隱私權與安全性 → 檔案與檔案夾」裡給「終端機」或「Python」的權限，可以留著或關掉。

## 7. 壞了的時候

要附的東西：

1. **面板或小視窗的截圖**：出錯那一行按「詳細」展開之後再截（⇧⌘4 再按空白鍵，點那個視窗）。
2. **終端機視窗的截圖**：雙擊 `iPLoT.command` 時跟著開的那一個；安裝、Python 版本、介面開不起來的訊息都在這裡。
3. **`logs/iplot.log`**：在 iPLoT 資料夾裡的 `logs/`。只有 iPLoT 自己出錯（訊息區寫「核心錯誤：……詳細內容在 logs/iplot.log」）時才會有。
4. 互通的捷徑出問題：`iPLoT/modules/互通/.sync-error`（以 `.` 開頭，Finder 按 ⇧⌘. 才看得到）；或「互通」視窗的「上一次同步的問題」那一區的截圖。
5. 版本：面板的標題（例如「iPLoT v0.6.0」）、macOS 的版本（蘋果選單 →「關於這台 Mac」）、終端機打 `python3 --version` 的結果。
6. 做了什麼之後出的事、能不能每次都重現。

或按錯誤旁邊的「回報這個問題」（第 10 節）：版本、作業系統、Python、出錯的模組與錯誤內容它會整理好、先遮掉路徑給你看，再用瀏覽器開到 iPLoT 的 GitHub 討論區、由你按送出。上面那幾樣不要直接放上去：論壇是公開的，截圖、`logs/iplot.log`、`.sync-error` 都沒有遮過，「詳細」展開的那一段和終端機視窗裡有家目錄的路徑、帳號名，在「科學計算」裡出的錯還有學生資料夾的名字（姓名、學號）。要在 GitHub 上附檔，附 iPLoT 存在 `modules/回報與討論/回報/` 的那個 `.txt`（遮過、你看過的那一份，第 10.1 節第 4、7 步）；截圖一定要附的話，拖進留言框之前先確認裡面沒有路徑、帳號名、學生的名字。

傳給：（交付時填上聯絡方式）。

面板開不起來、想先救急：在終端機進到 iPLoT 資料夾，打 `python3 main.py --safe`，開的是不用介面套件的「安全模式」（標題多了「（安全模式）」），只看 `modules/` 裡的模組。

## 8. 科學計算：助教怎麼收、怎麼看

「科學計算」（🎓）是給一門課收作業、看作業的模組，從工作坊裝。老師的作業包匯進來，面板上長出 HK1–HK12；TronClass 下載的作業收進來，一個學生一格；雙擊一格，用課程自己的 Python 另開一個視窗，照原樣跑那個學生交的檔。學生那邊什麼都不用改：照老師發的方式寫，交 `HKn.txt`。

用到的只有面板本來的操作（第 2 節）：雙擊執行；按一格右上角的「▸」進下一層；按上面那一列的「iPLoT」回最上層。

### 8.1 從工作坊裝

1. 在面板雙擊「工作坊」。清單上「科學計算」的狀態是「未安裝」，按「安裝」。關掉清單的視窗，面板上多一格「科學計算」（🎓），右上角有「▸」。
2. 按「▸」進去，上面那一列變成「iPLoT ▸ 科學計算」。裡面兩格：「匯入作業包」（📦）、「收作業」（📥）。
3. 這三格第一次雙擊時，各問一次「『<名稱>』是從外面裝進來的，第一次執行前確認：要執行嗎？」。按「確定」，之後不再問。

「科學計算」要等 M6 的人工驗收做完、研究助理傳上去，才會在清單上。給做 M6 Task 15 的人：不要用 `tools/publish.py --modules` 發：那會整份重寫凍結的 `index.json`；用 iplot-modules 的上傳表單（設計第 9.3 節）。

### 8.2 匯入老師的作業包

1. 拿到老師的 `t2026fscSpace` 資料夾（裡面是 `HK1.txt`…`HK12.txt` 與各份的 `HKnSpace/`）。拿到的是 zip 的話，先在 Finder 雙擊解開：下一步的選擇視窗只能選資料夾。
2. 在「iPLoT ▸ 科學計算」雙擊「匯入作業包」，出現選資料夾的視窗，選 `t2026fscSpace`。按取消：訊息區「沒選資料夾，沒有匯入」。
3. 訊息區「匯入了 HK1–HK12（新 12、更新 0）」，多出十二格。

面板照名字排：HK1、HK10、HK11、HK12、HK2、HK3……HK9，最後是「匯入作業包」「收作業」。HK10 排在 HK2 前面是正常的。

- 雙擊一份（例如「HK5」）跑的是老師自己的那一份，看起來跟按學生的一樣（見 8.5）。
- 老師改了題目：再匯入一次。只換題目（`HKn.txt`），老師的資料檔整份複製進去（同名的蓋掉、新的補上）；收進來的學生不動，他們的資料檔複本也不會跟著換，要的話再收一次。
- 選的資料夾裡一個 `HKn.txt` 都沒有：「收到的東西裡沒有 HK<n>.txt；要給的是老師的 t2026fscSpace 資料夾或它的 zip」，什麼都不做。

### 8.3 裝課程套件

學生的作業用到 numpy、matplotlib、torch 這些套件。它們裝進「科學計算」自己的 `.venv`（用 iPLoT 在用的那個 Python 建），不碰 iPLoT 的介面套件，也不碰系統的 Python。分兩批裝：

1. 在最上層雙擊「科學計算」。第一次會先建 `.venv`（訊息區「在建 .venv …」），接著問「要裝課程套件的基本那批（HK1–HK8 用的）嗎？numpy、matplotlib、scipy、Pillow、opencv-python、pandas、scikit-learn、PyWavelets。約 480 MB，裝進 科學計算/.venv；網路慢的話要很久，裝的時候別的按鈕要等它裝完」。按「確定」。
2. 一個一個裝。訊息區每 5 秒一行「<套件>：<pip 印的最後一行>」。裝完一句「已裝 numpy、…；第二批（HK9–HK12 用的 torch 那些，約 1.1 GB）再按一次「科學計算」」。
3. 再雙擊一次「科學計算」：問第二批（torch、pykan、PyYAML、tqdm、torchdiffeq；Apple Silicon 的 Mac 多一個 mlx-lm），約 1.1 GB。按「確定」。
4. 兩批都在之後再按，只說「課程套件都在」。按取消：「沒裝」。

- 訊息區可能好幾分鐘沒有新的一行：pip 下載大的檔（例如 torch）時不印進度。不是停住了。
- 裝的時候，面板上別的格子要等它裝完；在面板裡按的，中途停不掉。挑有空的時候裝。
- 在開發用的 Mac 上，那天的網路時快時慢（約 100 KB/s 到 3 MB/s），兩批從零裝完約 50–60 分鐘。兩批都裝好，`.venv` 約 1.6 GB（Apple Silicon 的 Mac，含 mlx-lm）。
- 只看 HK1–HK8 的話，第二批可以不裝。
- 某一個裝不了：最後一句寫「裝不了 <套件>（原因）」，其他照裝。基本那批有裝不了的，那一句照樣說「再按一次」，但再按時先問的是基本那批還缺的那幾個，都裝好了才問第二批。
- mlx-lm 只有 Apple Silicon 的 Mac 有。別的機器上第二批不列它；HK9 要在 Apple Silicon 的 Mac 上看（見 8.6）。
- Python 3.14 也可以：課程套件在 3.14 都有現成的安裝檔（在 Apple M2、macOS 26.5 上查過）。HK9 要的 mlx，那台拿到的是 macOS 26 用的那一版；更舊的 macOS 裝不裝得起來，沒有試過。

### 8.4 收作業

1. 從 TronClass 下載一份作業：一個學生是一個檔。交 `.txt` 的就是他的 `HK5.txt`；交 `.zip` 的，裡面是 `HK5.txt` 加上備份、自測之類。收進來的學生叫那個檔的名字（去掉 `.zip`、`.txt`），所以檔名就是學生的名字最好（例如 `B11234567_王小明.zip`）。
2. 在「iPLoT ▸ 科學計算」雙擊「收作業」，出現選檔的視窗：多選那些檔（一人一個 `.zip` 或 `.txt`），或選全班一包的 zip。0.6.0 的面板不能把檔拖到格子上，收作業就靠這一格；這個視窗只能選檔，不能選資料夾（要整個資料夾一起收，見下面「誰是一個學生」第 3 條）。
3. 檔名裡看得出 HKn 的，收進那一份。看不出來的，問一次「<檔名> 的名字裡看不出是哪一份作業：收進哪一份？（例如 HK5）」，打「HK5」按「確定」。不打或按取消：「沒說是哪一份，這幾個沒收：…」。
4. 這批用到 `.venv` 裡還沒有的套件時，問一次「這批用到還沒裝的套件：…。現在裝進 科學計算/.venv？」。按「確定」就裝；取消的話照收、不裝。課程套件兩批都裝好的話，通常不會問。一次選了不同份作業的 zip（例如 HK5 和 HK6）時，一份一份收：每一份各問一次（前一份裝好的不再問），訊息區也是每一份各一句。
5. 訊息區一句「收了 N 份進 HK5（新 a、覆蓋 b）」（N 是 a 加 b；這批有新格式的檔時，括號裡前面多「舊格式 c、新格式 d；」），後面接有問題的那幾份。進「HK5 ▸」，一個學生一格。

**誰是一個學生**：

1. 一樣東西是一個學生。選進來的每個檔、zip、資料夾各是一個人，名字就是它的名字（去掉 `.zip`、`.txt`、`.py`）：`王小明.zip` 收進來是「王小明」、`李大華.txt` 是「李大華」。一個人的 zip 或資料夾裡，不管放在第幾層，收的是檔名就叫 `HK5.txt`（或 `HK5.py`）的那一份；沒有的話，收看得出是作業的那一份（檔名有 HK5 的先）。其他的 `.py`、`.txt`（備份、自測、筆記）是多交的，不收，那一句一個一個列出名字。
2. 全班一包是包裝。zip 或資料夾裡有兩樣以上（子 zip、子資料夾、`.py`、`.txt`），而且它自己直接底下沒有 `HK5.txt`、`HK5.py`，它就是包裝：裡面每一樣各自再照第 1 條看，一層一層往下。名字就是 HK5 的 zip 或資料夾（`HK5.zip`、一個叫 `HK5` 的資料夾；大小寫、前面補 0 都算）一律是包裝，不是學生；名字只是含著 HK5 的（`HK5_王小明.zip`、`B11234567_HK5`）照第 1 條是一個學生。`科學計算_HK5_全班.zip` 這種全班一包，裡面有兩樣以上就是包裝。只包了一層的也一樣：`全班.zip` 裡只有一個資料夾、那個資料夾裡一人一個資料夾，收進來的是那幾個人。資料夾裡只放著一個 zip 時（例如只有一個人遲交），那個 zip 就是學生，用 zip 的名字。
3. 收的是一個資料夾時，裡面的 zip 會解開；zip 裡的 zip 再解一次，第三層不解。面板的「收作業」只能選檔；要把放 TronClass 下載下來那些檔的資料夾整個收進來，用批次模式 `python3 hk_tk.py --batch <資料夾> --hk HK5`（8.8），或「互通」的一行指令 `python3 ~/iPLoT/modules/互通/run.py ~/iPLoT/modules/科學計算/HK5 <資料夾>`（第 3 節；iPLoT 不在 `~/iPLoT` 就換成它的位置）。
4. 其他不猜，但會說。收完的名字看起來是檔名（例如 `HK5`、`HK5-2`、`B11234567_HK5`）時，句尾提示「這幾份的名字看起來是檔名不是學生（…）：把檔（或 zip）改成學生的名字再收一次」。選的資料夾直接放著一個沒改名的 `HK5.txt` 時，整個資料夾會被當成一個人，裡面別人的檔都列在「多交的」（收之前先把那個 `HK5.txt` 改成學生的名字）；被折進來的檔裡有在 zip 裡、又看得出是作業的（別人的 zip 放在旁邊）時，句尾另外提示「<資料夾> 直接放著一個 HK5.txt，所以整個資料夾被當成一個人：把它改成那個學生的名字再收一次」。在子資料夾裡的（多半是自己放的舊版，例如 `李大華/舊/HK5.txt`），或收的本來就是一個人的 zip（`王小明.zip` 裡有 `HK5.txt` 和 `old/HK5.txt`），只列在「多交的」，不提示。

收不對、不修的：下面幾種跟對的收法長得一模一樣，分不出來；每份作業都收進來了（沒有人少收），只是名字不對。名字裡沒有 HK5 的，句尾不會提示，收完看一下「HK5 ▸」的名單。

- 全班一包裡只有一個人有作業：全班的資料夾只有一個人的資料夾（`全班/B1/HK5.txt`），或 `全班.zip` 裡 `B2/HK5.txt` 旁邊都是別人的空資料夾 → 學生叫「全班」。跟一個人把作業放在子資料夾裡（`王小明/作業/HK5.txt`，叫「王小明」）一樣。批次模式給的 zip 裡多包了一層 `全班/` 也是這樣。
- 全班一包的 zip 名字只是含著 HK5、裡面又只有一個人（`HK5-重交.zip` 裡只有 `B1/HK5.txt`）→ 學生叫「HK5-重交」（這一種有「名字看起來是檔名」的提示）。只收一個人的重交，選那個人自己的檔，或把 zip 改名成 `HK5.zip`。
- 一個人的資料夾裡，兩個版本各放一個子資料夾（`王小明/v1/HK5.txt`、`王小明/v2/HK5.txt`）→ 兩個學生「v1」「v2」。跟全班一人一個資料夾（`全班/B1/HK5.txt`、`全班/B2/HK5.txt`）一樣。
- 一個人的 zip 裡沒有檔名剛好是 `HK5.txt`（或 `HK5.py`）的，而有兩個以上的 `.py`、`.txt`（`王小明.zip` 裡是 `main.txt`、`backup.txt`）→ 學生叫「main」「backup」。跟全班一人一個檔的 zip 一樣。檔名裡有 HK5 的（`HK5_v2.txt`）會有「名字看起來是檔名」的提示。
- 一個人的 zip 裡又包了一個名字就是 HK5 的 zip（`王小明.zip` → `HK5.zip` → `sub/HK5.txt`）→ 學生叫「sub」。跟全班一包裡包了一層 `HK5`（`全班.zip` → `HK5/` → `B1/HK5.txt`，收進來的是 B1）一樣。

遇到了：把名字不對的那幾格的資料夾丟進垃圾桶（8.10），把那個人交的東西照第 1 條整理好（正本改名成 `HK5.txt`、放在最上層，或整個 zip 改成學生的名字），再收一次。

名字裡的 `/ \ : * ? " < > |` 與開頭的 `.` 會拿掉；同一批撞名的，後面加「-2」「-3」。只收 `.py` 與 `.txt`；別的檔、解不開的 zip 不收，在學生那一層的（選進來的、全班一包直接底下的）列名字，一個人交的 zip 或資料夾裡的只計數。

**再收一次**：同一個名字的學生，覆蓋他交的檔（最新的贏），算在「覆蓋」裡。

**那一句後面可能接的**（有才出現）：

- 「k 份有語法錯誤（…）」「k 份不是 UTF-8（…）」「k 份不是 HK5 的作業檔（…）」：括號裡是名字。這幾份照樣收、照樣有一格，按下去會跳出錯誤的框（8.5）。
- 「k 份新格式檢查不過（名字：哪一條）」：見 8.7。
- 「k 份新格式沒收：hk_page.py 不在 hk_tk.py 旁邊（…）」：批次模式只複製了 `hk_tk.py` 時會出現，見 8.8。
- 「k 個檔不是 .py/.txt，沒收（…）」「k 個資料夾或 zip 裡沒有 .py/.txt，沒收（…）」「k 個 zip 解不開，沒收（…）」「k 個第三層的 zip 沒解，沒收（…）」：學生那一層（選進來的，或全班一包直接底下的）交的不是 `.py`、`.txt`（`.rar`、`.pdf`、`.docx`、空的資料夾），括號裡是名字，在資料夾或 zip 裡的寫出路徑（例如 `HK5.zip/B2`、`下載/王小明.zip`）。解不開是 zip 壞了、要密碼、或壓縮法不支援；第三層見「誰是一個學生」第 3 條。這幾個要自己打開來看。
- 「略過 k 個不是 .py/.txt 的檔」：一個人交的 zip 或資料夾裡的 `.pdf`、圖之類（在他的格子裡看不到），只計數。
- 「多交的 k 個檔沒收（王小明：HK5_backup.txt、test_HK5.py；…）」：一個人交的 zip 或資料夾裡，正本以外的 `.py`、`.txt`，冒號前是學生、後面是檔（在子資料夾或 zip 裡的寫出路徑，例如 `王小明.zip/HK5.txt`）。
- 「擋掉 k 個路徑不安全（.. 或絕對路徑）的東西」：zip 裡名字不安全的檔不解開。
- 「老師的 HK5Space 還沒匯入，要用資料檔的 case 會缺檔」：還沒做 8.2 就收了。之後再匯入，已經收的學生不會自動補資料檔，要再收一次。
- 裝套件的結果：「已裝 …」「裝不了 …（原因）」「沒裝：…」；`.venv` 還沒建時是「.venv 還沒建，套件沒掃」。
- 最後是上面「誰是一個學生」第 4 條的兩種提示。

### 8.5 看一個學生的作業

在「iPLoT ▸ 科學計算 ▸ HK5」雙擊一個學生。訊息區「<學號姓名>：HK5 的視窗開了（在 Dock 上找 Python）」，另開一個 800×800 的視窗，標題是「<學號姓名> — HK5」，裡面是老師的作業自己的那排按鈕。按視窗裡的 RUN 才會算、才有圖。

- 這個視窗是另一個程式（Dock 上的 Python），面板照常可以按別的。視窗通常開在最前面；不在的話，到 Dock 點 Python 的圖示。
- 剛裝好課程套件之後第一次按，要 4 秒以上才看得到視窗；之後每次約 1.1 秒（在開發用的 Mac 上量的）。
- 學生 `print` 的東西寫進他資料夾裡的 `執行紀錄.txt`，每按一次重寫。在那一格按右鍵 →「在資料夾中顯示」就找得到。
- 出錯時跳一個標題是「這份作業出錯了」的框，下面是完整的錯誤內容，視窗留著。按 RUN 之後才出的錯也一樣。
  - 語法錯：第一行是「語法錯誤：第 n 行」。
  - 缺套件：最後一行是「缺 x：<python> -m pip install <套件>」。把這一行冒號後面的指令貼到終端機打，裝好再按一次。
  - 不是 UTF-8：「這個檔不是 UTF-8（存檔時選 UTF-8 再交）」。
  - 交錯份、或根本不是作業（收作業時列在「不是 HK5 的作業檔」）：第一行是「這份不是 HK5 的作業檔：檔裡沒有 def HK5()」。
- `.venv` 還沒建就按：訊息區「課程的 .venv 還沒建：先按「科學計算」裝課程套件；這次用 iPLoT 自己的 Python 試」。
- HK6 的 case-1 畫出來是空白的：老師的原件本來就這樣（在老師自己的啟動器裡也一樣），不是收壞了。

### 8.6 HK9–HK12：要等，HK9 要 Apple Silicon

- 按 RUN 之後視窗凍住、不能按，是正常的：作業在按鈕裡直接算，算完畫面才會動。在開發用的 Mac 上，HK12 的 case-1 約 43 秒；HK5 的 case-1 第一次也要約 40 秒（第一次載入 scikit-learn）。訓練步數多的 case 更久。
- HK9 要一台 Apple Silicon 的 Mac：它用的 mlx-lm 只有那種 Mac 裝得了。別的機器上，要裝 mlx-lm 時說「這台機器裝不了，HK9 要在 Apple Silicon 的 Mac 上看」。
- HK9 第一次按 RUN，會從網路下載老師的作業用的模型（`mlx-community/Qwen2.5-1.5B-Instruct-4bit`，約 870 MB）。在開發用的 Mac 上約 3.5 MB/s，下載加載入 251 秒；這段時間視窗是凍住的。下載過一次就放在 `~/.cache/huggingface/hub`，之後每個學生都從那裡拿、不再下載。網路慢的話，先在終端機下載好（iPLoT 不在 `~/iPLoT` 就換成它的位置）：

  ```
  ~/iPLoT/modules/科學計算/.venv/bin/python -c "from mlx_lm import load; load('mlx-community/Qwen2.5-1.5B-Instruct-4bit')"
  ```

### 8.7 照 `docs/09` 寫的作業（新格式）

從下一份作業起，老師可以照 `docs/09_作業規範.md` 寫：一份作業一個 `.py`。收法一樣，用「收作業」選 zip；舊格式、新格式可以在同一批裡，會自動分辨。新格式的學生資料夾裡是他交的檔（改名成 `iplot.py`）、殼 `hk_page.py`、老師的資料檔複本。老師自己那一份放成 `科學計算/HKn/iplot.py`，旁邊放 `hk_page.py`（從 `科學計算/` 複製）與 `HKnSpace/`；「匯入作業包」只認舊格式的 `HKn.txt`。

雙擊一個新格式的學生（或老師的那一份）：

- 用課程的 `.venv` 另開一個程式，不問 case，一個一個 case 跑，關掉一個視窗才開下一個（程式是這樣寫的；Mac 預設的 macosx 後端上，人按關閉之後下一個有沒有出來，還沒親眼看過，見人工驗收）。有文字或數字結果的 case，先開一個「<作業名稱> — <case>（文字）」的視窗放那些字；有 `draw` 的 case，再開一個 matplotlib 的視窗畫圖，標題是「<作業名稱> — <case>」。沒有 `draw` 的作業（例如 `examples/` 的 HK8）只有文字那個視窗。
- 訊息區「<學號姓名>：<作業名稱> 的視窗開了（在 Dock 上找 Python）」。有時是「iPLoT 的 Python 沒有 …；改用課程的 .venv 另開視窗跑」：一樣開了，正常。
- 出錯不跳框：錯誤全文印出來，那個 case 跳過，接著下一個。面板是雙擊 `iPLoT.command` 開的話，印出來的字在跟著開的那個終端機視窗裡。新格式沒有 `執行紀錄.txt`。
- 收作業時，新格式的檔先做一次靜態檢查（`hk_page.py --check`，規範第 7 節）。不過的照收，那一句列「新格式檢查不過」。

### 8.8 沒有 iPLoT，或用 Windows

`hk_tk.py`（加上放在旁邊的 `hk_page.py`）就能收、能看，不用 iPLoT。要 Python 3.10 以上。Windows 上未經實機驗證。

1. 拿 `hk_tk.py` 與 `hk_page.py`，放在同一個資料夾：從裝了「科學計算」的 iPLoT 的 `modules/科學計算/` 複製，或在模組網站（`https://william10310406.github.io/iplot-modules/`）下載 `科學計算.zip` 解開（傳上去之後才有）。只複製了 `hk_tk.py` 也收得了舊格式，但新格式的檔不收，收完那一句多「k 份新格式沒收：hk_page.py 不在 hk_tk.py 旁邊（…）」：把 `hk_page.py` 放到 `hk_tk.py` 旁邊，再跑一次就收進來了，什麼都不用刪。
2. 在終端機進到那個資料夾，打：

   ```
   python3 hk_tk.py --batch <TronClass 的 zip> --kit <老師的 t2026fscSpace>
   ```

   `--batch` 要寫在最前面。`--batch` 後面也可以給一個資料夾（放 TronClass 下載下來、一人一個 `.zip` 或 `.txt` 的那個）：資料夾的名字看不出是哪一份，要加 `--hk HK5`；收進它旁邊的 `<資料夾名>_收件/`。可以加的：

   | 寫法 | 做什麼 |
   |---|---|
   | `--kit <資料夾>` | 老師的 `t2026fscSpace`；每個學生的 `HKnSpace/` 從這裡複製。不給的話是空的 |
   | `--out <資料夾>` | 收進哪裡；預設是 zip 旁邊的 `<zip 名>_收件/` |
   | `--venv <資料夾>` | 套件裝進哪個 venv；預設是 zip 旁邊的 `科學計算-venv/`（幾份作業共用） |
   | `--hk HK5` | zip 的檔名裡看不出是哪一份時，指定是哪一份 |
   | `--yes` | 要裝套件時不問 |

3. 終端機一行行說它在做什麼。zip 放在哪裡都可以（跟 `hk_tk.py` 同一個資料夾、它的子資料夾、別的地方都一樣收）；給的 zip 一定當作全班那一包，裡面誰是一個學生照 8.4。這批用到還沒裝的套件時問「這批用到還沒裝的套件：…。現在裝進 …？ [y/N]」，打 `y` 按 Enter 才裝。收完的那一句跟面板的一樣，只是 venv 沒建好時句尾是「venv 沒建好，套件沒掃」。
4. 跳出一個名單視窗，標題「<收件資料夾名> — N 份」，一列一個學生。後面有字的是有問題的：「語法錯誤」「不是 UTF-8」「不是作業檔」「檢查不過」（新格式）、「缺 x、y」（venv 裡沒有的套件）。雙擊一列或按「開」：開的視窗跟在面板裡按學生一樣（8.5、8.7）。venv 沒建好時，新格式的學生缺套件就不開，終端機最後一行是「RuntimeError: 缺 …：批次模式要先建好 venv（--venv，或 zip 旁邊的 科學計算-venv）」。關掉名單視窗，指令才結束。

Windows 上把 `python3` 換成 `py`（未經實機驗證）。HK9 只能在 Apple Silicon 的 Mac 上看：別的機器裝不了 mlx-lm，名單上那幾份會標「缺 mlx-lm」。

### 8.9 會多出來的東西

- 「互通」替每一份作業、每一個學生各做一個捷徑，名字像「科學計算 › HK5 › <學號姓名>」，都在 `modules/互通/捷徑/`：比作業的份數乘上全班人數還多幾個（「科學計算」「匯入作業包」「收作業」與每一份作業也各一個）。整個「捷徑」資料夾拖到 Dock 的話，那一排會很長。
- 「互通」視窗的「可以加上那一小段的模組」會列出每一份作業與每個學生的 `iplot.py`。不用按「加上」。
- 第一次按一份作業或一個學生時，iPLoT 把那個資料夾的 `iplot.py` 存一份進它自己的 `.history/`（內容沒變就不再存）。不影響執行。
- HK11 跑的時候，會在學生資料夾的 `HK11Space/` 裡寫 `figures/`、`model/`。
- 用「工作坊」更新或覆蓋「科學計算」時，整個資料夾（連 `.venv/` 與收進來的作業）先壓一份存進 `科學計算/.history/`，套件裝好之後這一份很大；之後每一份作業、每個學生第一次按，都會再問一次「是從外面裝進來的」。

### 8.10 資料存在哪

```

  .venv/                       課程的 Python 與套件（兩批都裝好約 1.6 GB）
  HK5/

    t2026fscSpace/

      HK5Space/                老師的資料檔
    <學號姓名>/                 收作業長出來的，一人一個

      執行紀錄.txt              上一次按的時候印出來的
      t2026fscSpace/

        HK5Space/              老師的資料檔複本

```

`.venv/` 與 `HK*/` 是各台電腦自己的：不在 iPLoT 的 git 裡，也不進工作坊發佈的包。要刪一個學生，把他的資料夾丟進垃圾桶；整門課不要了，把 `modules/科學計算/` 丟進垃圾桶（工作坊沒有「移除」，見第 6 節）。在 iPLoT 外面的：HK9 的模型在 `~/.cache/huggingface/hub`；裝套件時 pip 的下載快取在 `~/Library/Caches/pip`；批次模式的 `<zip 名>_收件/` 與 `科學計算-venv/` 在 zip 旁邊。

## 9. 上傳模組：把自己的模組放上工作坊

要有 GitHub 帳號、要開瀏覽器，不用 git、不用裝別的東西。傳上去的東西誰都看得到、誰都能下載執行，**沒有人審查**：收上傳的機器人只照規則擋（名字、zip 的形狀與大小、`iplot.py` 的語法、版本這些，每一種見 9.4），不看程式做什麼。

### 9.1 先看一眼資料夾裡有什麼

1. 在 Finder 打開模組的資料夾，按 ⌘⇧.（Command、Shift、句號）顯示隱藏的檔；再按一次又藏起來。
2. 看不到的檔 Finder 也會壓進去。`.venv`、`.history`、`__pycache__`、`.DS_Store` 這些，機器人會略過、不公開（「收到了」那一則底下會列出略過的）；模組自己存的設定與資料，看不到的也一樣（例如行事曆的 `設定.json`、互通的 `.python`），會公開出去。有這種檔的話，先把整個資料夾複製一份，在複本裡拿掉它們，再壓複本。`.venv` 不公開，可是算在 zip 的大小裡：表單說檔案太大，或機器人說「zip 超過 25 MB。」，多半是 `.venv`，一樣在複本裡拿掉。
3. 名稱就是資料夾名：清單上、別人的 `modules/` 裡都是這個名字。資料夾裡要有 `iplot.py`（全小寫）。

### 9.2 壓、傳

1. 在 Finder 對著模組的資料夾按右鍵，選「壓縮」，旁邊多一個 `<名稱>.zip`。中文的名稱沒關係：Finder 壓的中文名模組收得進來（2026-10-20 用真的 Finder zip 試過）。zip 的檔名有空白或括號也沒關係，例如旁邊已經有同名的 zip 時 Finder 壓出來的「整理桌面 2.zip」（推測，未親眼看）、瀏覽器下載的「x (1).zip」：GitHub 會自己改附件網址裡的檔名（2026-10-23 用這兩個檔名從表單傳過，網址裡變成 `2.zip`、`x.1.zip`），機器人照樣找得到附件。名稱看的是 zip 裡的資料夾，不看 zip 的檔名。
2. 在瀏覽器打開 `https://github.com/william10310406/iplot-modules/issues/new/choose`，選「上傳模組」。沒登入 GitHub 的話先登入。
3. 把 zip 拖進「模組的 zip」那一格；「這一版改了什麼（選填）」可以不填（模組裡有 `CHANGELOG.md` 的話以它為準）；勾「我知道上傳的東西誰都看得到、誰都能下載執行；收到之後，這個名字只有我的帳號能更新。」；按送出。
4. 一兩分鐘後，那個 issue 裡出現「收到了：「<名稱>」<版本>，<N> 個檔。網站更新之後（通常幾分鐘）在 iPLoT 按「工作坊」就看得到；…」，下面列出公開的檔，issue 關掉。過幾分鐘在 iPLoT 雙擊「工作坊」，清單上就有它，名稱底下一行「上傳者：@<你的帳號>」。

### 9.3 版本、名字、更新

- **版本**：模組裡有 `CHANGELOG.md` 的，照最上面那一節的版本（標題寫成 `## [1.2.0] - 2026-10-21`，版本只有數字與點），而且要比清單上現在的新，不然不收；那一節的第一段就是清單上的「這一版：…」。沒有 `CHANGELOG.md` 的，第一次是 0.0.1，之後每傳一次最後一段加一（0.0.1 → 0.0.2）。
- **名字**：歸第一個傳它的帳號，別的帳號不能用；大小寫不同、看起來一樣的寫法也算同一個名字。「作業系統」「更新」「工作坊」誰都不能傳；隨附模組的名字（開工、打開核心原始碼這些）是研究助理的。
- **更新**：改好之後照 9.2 再傳一次就是更新。裝過、沒改過的人，清單上那一列是「可更新」。

### 9.4 被退的時候

那個 issue 裡會有一句話說哪裡不對，issue 關掉。改好之後照 9.2 再開一個新的 issue（不要在舊的裡回覆）。每一種原因與那一句話，見 [iplot-modules 的 README](https://github.com/william10310406/iplot-modules#readme) 的「沒收的原因」。

下架、改名、把名字轉給別人，上傳的人自己做不了：找研究助理（第 7 節）。

## 10. 回報問題與討論

要有 GitHub 帳號、要開瀏覽器。論壇（`https://github.com/william10310406/iplot/discussions`）是公開的，任何人都看得到；送出之前一定會先給你看。

### 10.1 出錯的時候

1. 錯誤那一列按「回報這個問題」。「回報與討論」是從工作坊裝的話，第一次會先問「『回報與討論』是從外面裝進來的，第一次執行前確認：要執行嗎？」，按「確定」。
2. 開出一頁「回報這個問題」。最上面一行說遮了什麼（例如「已自動遮蔽：3 個路徑、1 個使用者名稱。」），接著是「論壇是公開的，任何人都看得到；送出前請再看一次，特別是學生的名字。…」。標題、內文都可以改：特別看學生的名字，錯誤訊息裡直接寫著的名字遮不到（10.4）。內文底下一行「網址長度 N／2000」；這一頁最下面一行是「完整報告已複製，GitHub 出錯或內容被截斷時，按 ⌘V／Ctrl+V 貼上。」。
3. **按之前先確認瀏覽器已經登入 GitHub。** 沒登入的話，登入之後 GitHub 可能出錯、填好的內容會不見（研究助理 2026-10-24 在 Safari 無痕視窗看到：登入之後 500）。
4. 按「在瀏覽器打開」：完整的回報先複製到剪貼簿、存在 `modules/回報與討論/回報/`（檔名像 `20261025-143005-KeyError.txt`：日期、時間、錯誤的種類），瀏覽器開在「問題回報」分類的新增頁，標題、內文都填好了（未核），內文最後一句就是上面那句「完整報告已複製…」。那一頁說「已經在瀏覽器打開了。登入 GitHub、按 Start discussion 才會公開。…」，最後一句是「完整的回報已經複製到剪貼簿。」。剪貼簿沒複製成的話，最後一句是「剪貼簿沒有複製成功：請在下面這一格全選、複製。」，完整的回報放在下面那一格；這時候網址內文的最後一句與這一頁最下面那一行都不說「已複製」（剪貼簿裡還是之前複製的東西，可能是沒遮過的，不要貼上），改成「剪貼簿沒有複製成功：完整報告存在 iPLoT 的 回報/<檔名>；GitHub 出錯或內容被截斷時，從那個檔複製全文、直接貼上。」。存不了檔的話，那一句會說「存不了檔（…）」，完整的回報只在剪貼簿裡；存不了檔、剪貼簿也沒複製成的話，完整的回報只在下面那一格，最後那一句是「剪貼簿沒有複製成功：完整報告在 iPLoT 那一頁下面那一格；GitHub 出錯或內容被截斷時，從那裡複製全文、直接貼上。」。之後按「再複製一次」，最下面那一行也照那一次成不成換。
5. 在瀏覽器裡看一次，按 Start discussion（未核）。
6. GitHub 出錯的話（例如第 3 步看到的 500；填好的內容不見了也算）：確認瀏覽器已經登入之後，回到那一頁再按一次「在瀏覽器打開」。還是不行：那一頁下面多了一格「GitHub 出錯時，打開這個新增頁，把內文整個換成完整的回報：」，把那個網址複製到瀏覽器打開；回到那一頁按「再複製一次」（複製網址時剪貼簿被蓋掉了），在新增頁的內文直接貼上（⌘V）；標題也要填，完整的回報第一行就是標題。
7. 內容太長、網址放不下的時候，網址裡的會截掉一段（標題超過 200 字先截到 200 字，再截 traceback 的中間；按之前，「網址長度」那一行就會說「traceback 會從中間截斷…」，送出之後那一句也會說）。完整的在 `.txt` 裡：關掉那一頁之後，iPLoT 會在 Finder 指出那個 `.txt`，可以拖進 GitHub 的留言框當附件（未核：GitHub 收不收 `.txt` 的附件沒有試過）。瀏覽器打不開的時候，那一頁說「瀏覽器打不開。把下面這串網址整個複製到瀏覽器的網址列；…」，網址放在下面那一格；關掉那一頁之後，iPLoT 一樣在 Finder 指出那個 `.txt`。
8. 不送的話，直接關掉那一頁：沒按「在瀏覽器打開」就什麼都不存。

### 10.2 安全模式、Linux（tkinter 面板）

安全模式與後備面板（Linux 也是）沒有那一頁，改成用編輯器打開一份草稿：錯誤那一列一樣有「回報這個問題」，按下去，訊息區先一行說遮了什麼，文字編輯器打開草稿（第一行是標題，空一行之後是內文），並問「草稿在 回報/<檔名>，已經用編輯器打開。改好、存檔之後按「確定」就用瀏覽器打開；按「取消」就不送，草稿留著。」。草稿在 `modules/回報與討論/回報/`（`.md`），只留在這台電腦。

- 改好、存檔，按「確定」：讀回來再遮一次，存成 `.txt`、複製到剪貼簿，再開瀏覽器到新增頁；訊息區說完整的回報在哪裡、GitHub 出錯時怎麼貼。網址內文的最後一句跟訊息區說的一樣：複製成了是「完整報告已複製，GitHub 出錯或內容被截斷時，按 ⌘V／Ctrl+V 貼上。」；剪貼簿沒複製成的話是「剪貼簿沒有複製成功：完整報告存在 iPLoT 的 回報/<檔名>；GitHub 出錯或內容被截斷時，從那個檔複製全文、直接貼上。」（不要貼剪貼簿裡原本的東西），也存不了檔時是「剪貼簿沒有複製成功：完整報告在 iPLoT 的訊息區；GitHub 出錯或內容被截斷時，從那裡複製全文、直接貼上。」。截過、或瀏覽器打不開（網址寫在訊息區），iPLoT 馬上在檔案總管（macOS 是 Finder）裡指出那個 `.txt`。存不了檔、剪貼簿也沒複製成的話，遮過的完整回報寫在訊息區的下一則，從那裡複製（不要從草稿複製：草稿是改過、還沒再遮的）。
- 按「確定」之前草稿被刪掉了，或存成了 UTF-8 以外的編碼（例如 Big5）：只有一句「讀不回草稿（…），沒有送出；…請再試一次（會開新的一份）」，編碼不對的那一句另外說「這次存成 UTF-8」。
- 按「取消」：「沒有送出；草稿留在 回報/<檔名>」。

### 10.3 提建議、問問題、看論壇

雙擊面板上的「回報與討論」（💬），開出一頁四顆鈕。最上面一行「論壇是公開的，任何人都看得到。「回報問題」會先讓你看過、改過要送出的內容；其他三個直接用瀏覽器打開。」

- 「回報問題」：沒有錯誤訊息的問題（畫面不對、太慢、結果不對）。先在旁邊的清單選相關的模組（只列最上層的；可以「（不指定模組）」），按下去換成跟 10.1 一樣的那一頁，內文的「發生了什麼」要自己寫，沒有「錯誤」那一節；之後照 10.1 的第 3 步做。
- 「提建議」「問問題」：瀏覽器開在「功能建議」「問答」分類的新增頁，內文最後帶一行 iPLoT 的版本、作業系統與 Python 的版本（未核；那一頁上看得到是哪一行，沒有路徑）。
- 「看論壇」：瀏覽器打開論壇。
- 瀏覽器打不開的時候，那一頁說「瀏覽器打不開。把下面這串網址整個複製到瀏覽器的網址列。」，網址放在下面那一格。

安全模式與後備面板（Linux 也是）沒有這一頁：按一下「回報與討論」，問「要做什麼？輸入 1 回報問題、2 提建議、3 問問題、4 看論壇」，打數字按「確定」；1 走 10.2 的草稿，2、3、4 直接開瀏覽器（打不開就把網址寫在訊息區）。

### 10.4 遮了什麼、沒遮什麼

**遮得到的。** iPLoT 不登入、不存密碼、不連網：它只把內容填進一個網址交給瀏覽器，按送出的一定是你。開瀏覽器之前，遮過的完整回報都先存在 `modules/回報與討論/回報/`（存不了會說），並試著複製到剪貼簿，所以 GitHub 登入之後內容不見了也還貼得回去；`回報/` 不會跟著 iPLoT 的包或 git 發出去。網址、剪貼簿、`.txt` 裡的都是遮過的那一份：家目錄、使用者名稱、iPLoT 與 Python 以外的路徑（出錯的模組資料夾裡第一層的檔名留著）、模組的原始碼行、下一層模組的名字（例如學生的資料夾）、長得像學號的、信箱，都換成 `<HOME>`、`<PATH>`、`<疑似學號>` 這種記號（模組的原始碼行換成「（原始碼已略過）」）。存不了檔、讀不回草稿時那一句裡的路徑也先遮過。送出前一定先給你看；按送出的時候用同一套規則再遮一次，你自己貼進去的路徑也遮。

**遮不到的。** 長得不像路徑、學號、使用者名稱的個人資料遮不到，例如錯誤訊息裡直接出現的學生姓名（`KeyError: '王小明'`）。使用者名稱少於 3 個字的，在路徑以外的地方不會自動遮（說遮了什麼的那一行會提醒）。另外有七種路徑的寫法照規則也遮不到：沒有引號的相對路徑（numpy 的 `X not found.` 這種）；前面那個引號緊貼著英文字母或數字的路徑（例如 `crab'HK2/…'`：那個引號被當成撇號）；路徑自己的兩個引號外面各還有一個落單的同一種引號的路徑（哪兩個引號配成一對都說得通）；沒有引號的絕對路徑，最後一段有空白、`'` 或括號的（例如 `Wang Xiaoming.txt`：空白後面那一半留著；`(1)王小明.csv` 也一樣）；中文引號裡的相對路徑（或只有一段的、`//` 開頭的路徑）、名字裡又有同一種閉引號的（例如 `「HK2/「論語」心得_王小明.txt」`：`心得_王小明.txt」` 留著）；路徑裡有 `"`、`<`、`>` 或換行的（後半段留著）；括號裡的路徑，裡面又有一個落單的 `)` 的（例如 `(…/學生)/王小明.py)`：`/王小明.py)` 留著）。所以一定要自己看過再送。網址交給瀏覽器之後的事 iPLoT 管不到：瀏覽器的歷史紀錄、擴充功能看得到整串網址（遮過的那一份），按了送出就是公開的貼文。剪貼簿裡的那一份，這台電腦上別的程式也讀得到，直到下一次複製把它蓋掉；`回報/` 裡的 `.txt` 一直留著，不會自己清，不要了就自己丟進垃圾桶。Windows 上太長的網址可能被系統截掉，未經實機驗證。網頁那一頭的複製在 Windows 上還沒試過，macOS 上也還沒在真的視窗裡試過；複製不成時那一頁會把完整的回報放出來，讓你自己全選、複製。tkinter 面板用的是 Tk 自己的剪貼簿，複製不成也會在訊息區說。
