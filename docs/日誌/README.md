# iPLoT 每日日誌

**兩週使用期間起始日：未設定**

（設定方式：由使用者決定哪一天是第 1 天，再把上面這一行改成 `**兩週使用期間起始日：YYYY-MM-DD**`——指令不會自己設，也不會問；還沒設定時，`/日誌` 會在摘要裡寫「需要問他」。設定之後 `/日誌` 在第 7 天與第 14 天會提醒做檢視。）

## 這是什麼

一天一個檔：`docs/日誌/YYYY-MM-DD.md`。記的是當天發生的事，不是 commit 訊息的複製——要的是「隔了一個月再看，還知道那天做了什麼、決定了什麼、用了什麼、卡在哪」。沒有任何 commit 或文件活動的日子不建檔。

2026-10-02 到 2026-11-05 的日誌是事後補寫的，資料來源是 `git log --all`、`docs/plans/` 各里程碑的設計／工作單／回報、`CHANGELOG.md` 與各模組的 `CHANGELOG.md`、`docs/05_使用紀錄.md`、`docs/reports/2026-11-05-現況盤點報告.md`。從 11-05 以後的日誌由 `/日誌` 每天整理。待辦清單見 [待辦.md](待辦.md)。

## 每篇的格式

```
# YYYY-MM-DD
## 做了什麼        用白話寫做了什麼（不是貼 commit 訊息），每條後面附相關 commit 短 hash
## 決定            當天定下的設計決定，附 D 編號；沒有就省略這一節
## iPLoT 使用紀錄  當天實際「使用」iPLoT 做了什麼、卡在哪；沒有就寫「無」
## 想要但做不到    每條註明：只要加模組／需要動核心；沒有就省略這一節
## 留下的          沒做完、延後、待驗收的事
```

幾條規矩：

- **使用不等於開發。**「iPLoT 使用紀錄」只寫有證據的使用（`docs/05_使用紀錄.md` 的紀錄、驗收紀錄、當事人說的）。開發時為了驗證而跑的測試、探針、驗收腳本，不算使用；補寫的過去日子，大部分是「無」，照實寫。
- **repo 是公開的。** 日誌裡不放本機路徑（家目錄、外接硬碟的路徑）、不放帳號以外的人名、不放學生的任何資料。人一律用角色稱呼：老闆、研究助理、上傳者、同事。
- **不確定是哪天發生的**，寫在最接近的那天並標「（日期推定）」。沒有證據的事不編。
- 同一天已有日誌時，`/日誌` 是合併進去，不覆蓋。

## 怎麼用 `/日誌` 與 `/下一步`

操作這兩個指令的是使用者的助理；使用者本人不會記得自己做了什麼，所以**兩個指令都不問任何問題**，一律從證據重建。

**`/日誌`**：每天收工前跑一次。它從四個地方重建「今天（Asia/Taipei）做了什麼」：

1. iPLoT repo——所有分支與所有 worktree 的 `git log`、今天改過的 `docs/`、還沒 commit 的變更（只列檔名）、還沒合進 main 的分支。
2. 使用者今天的 Claude Code 對話紀錄——整理交代了什麼、做到哪、卡在哪、做了什麼決定，用自己的話摘要，不貼原文。
3. iPLoT 實際被使用的證據——`logs/` 與各模組 `.history/` 的快照時間（快照＝有人按了那個模組）。「iPLoT 使用紀錄」只寫這個，不把開發當成使用。
4. GitHub（只讀）——iplot 的 Discussions、iplot-modules 與 iplot 的 issue，今天有沒有新的。

接著寫（或合併進）今天的日誌、更新下面的索引、檢查沒有本機路徑，只 commit `docs/日誌/` 底下的檔，訊息「日誌：YYYY-MM-DD」，最後回給助理三行以內的摘要。每一條都要有出處（commit hash，或「對話紀錄」「快照」「Discussions #n」等）；找不到證據的不寫，無法判斷的放進「留下的」並標「無法判斷：…」。起始日還沒設定、或需要使用者決定的事，在摘要裡寫成「需要問他：…」，由助理轉問。

在第 7 天與第 14 天，它會額外提醒做檢視，並把這段期間「想要但做不到」按「只加模組」與「需要動核心」分組彙整。

**`/下一步`**：每天寫完日誌後排明天的事，或使用者不知道要做什麼的時候跑。它讀 [待辦.md](待辦.md)、最近 3 天的日誌與分支狀態，更新待辦，挑出最該做的 1–3 件事，產出一段可以直接傳給使用者的訊息：要在 Claude Code 做的附完整提示詞，以及建議的模型、投入程度、要不要開 Ultracode（能用小模型就不用大的）；要用滑鼠自己做的（例如人工驗收）附步驟。最後只 commit `待辦.md`。

指令本身在 `.claude/commands/日誌.md` 與 `.claude/commands/下一步.md`。**[待辦.md](待辦.md) 是目前所有該做的事的唯一清單**；兩週使用期間不排新功能，只排修補、驗收、使用。
