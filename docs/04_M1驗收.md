## 5. 沒做到的事

- CI 沒有跑：這一版不建遠端、不 push。`ci.yml` 已加 Python 3.10／3.12 矩陣與 `bash tests/smoke.sh`；macOS runner 能不能開 Tk 視窗要 push 之後才知道（開不了就把 smoke 那一步標 `continue-on-error`）。
- Python 3.10 只做了 import 檢查（`/opt/homebrew/bin/python3.10`，把 `tkinter` 塞成 `None` 後 import `core.*` 與解析 `main.py`），完整測試套件沒有在 3.10 上跑（那個直譯器沒有 pytest，規定不裝）。
- `tests/test_scan.py::test_case_must_match_exactly` 與 `test_create.py::test_never_overwrites_differently_cased_iplot` 只在不分大小寫的檔案系統（macOS 預設）上有意義，在 Linux 前者會 skip、後者不會失敗。
- 「重新啟動」用 `os.execv` 自己（規格 §8.5），macOS 會在 Terminal 印一行 `Task policy set failed`；要完全乾淨得改成開新程序再結束自己，留給 M2 評估。

- `logs/` 寫不了時，`core_error` 那句仍指向 `logs/iplot.log`，文字不準；改文字要動 `core_error` 鍵，M2 再議（v0.1.1 的 D45 只保證核心錯誤照樣進面板）。
