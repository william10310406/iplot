# 作業規範（v2，2026-11-06）

一份作業＝一個 Python 檔。寫成這個樣子的作業：學生在終端機打 `python3 HK1.py` 就能跑、助教在 iPLoT 裡按一顆按鈕就能跑、出作業的老師在 iPLoT 裡選一個 case 就能看到結果。這份規範給「課程作業」模組（`modules/課程作業/`）用；v0 的檔只有「科學計算」那個凍結的模組收（見第 6 節）。

這份規範有一個會動的對照物：殼 `modules/課程作業/作業類型/算完畫圖/coursework.py`。規範與殼對不上時，以殼為準、回頭改這份。

## 1. 一個檔長什麼樣

```python
REQUIRES = ["numpy", "matplotlib"]                       # 用了別的套件就加在這；自己跑一次會自動補
import coursework; coursework.ensure(REQUIRES, __file__)  # 缺的在這一行裝好，裝完才往下 import
import numpy as np
from pathlib import Path
from matplotlib.animation import FuncAnimation

# ── 從這裡開始是作業 ──
NAME = "HK1 範例：一顆球繞圓"                            # 頁面標題
DOCS = [("Uniform circular motion", "https://en.wikipedia.org/wiki/Circular_motion")]
NOTE = """筆記寫這裡。純文字。"""
DATA = Path(__file__).resolve().parent / "HK1Space"      # 資料檔放這個資料夾；沒有資料檔就刪掉這行
CASES = {
    "case-1": dict(r=1.0, w=1.0, label="半徑 1、角速度 1"),
    "case-2": dict(r=2.0, w=0.5, label="半徑 2、角速度 0.5"),
}

def compute(case):
    """算。純計算、不畫圖、不開視窗；回一個 dict，畫圖和數字都從它拿。"""
    p = CASES[case]
    t = np.linspace(0, 2 * np.pi / p["w"], 200)
    return {"t": t, "x": p["r"] * np.cos(p["w"] * t), "y": p["r"] * np.sin(p["w"] * t)}

def draw(fig, run):
    """畫。在給你的 fig 上畫；要動畫就回傳 FuncAnimation，靜態圖回 None；不要畫圖的話，整個函式換成一行 draw = None。"""
    ax = fig.add_subplot(111)
    ax.set_aspect("equal"); ax.set_xlim(-2.2, 2.2); ax.set_ylim(-2.2, 2.2)
    ax.plot(run["x"], run["y"], lw=0.8, alpha=0.4)
    dot, = ax.plot([], [], "o")
    def update(i):
        dot.set_data([run["x"][i]], [run["y"][i]])
        return (dot,)
    return FuncAnimation(fig, update, frames=len(run["t"]), interval=30, blit=False)

def stats(run):
    """幾個數字，頁面照順序列；不要的話整個函式換成一行 stats = None。"""
    return [("週期 T", f"{run['t'][-1]:.3f}"), ("點數", str(len(run["t"])))]

# ── 以下不用改 ──
HOMEWORK = dict(name=NAME, docs=DOCS, note=NOTE, cases=CASES, compute=compute, draw=draw, stats=stats, file=__file__)
if __name__ == "__main__":
    raise SystemExit(coursework.main(HOMEWORK))
```

上半是作業，學生改的；下半三行是固定的，不要動。`coursework.py`（殼）放在同一個資料夾（打包時一起給）。

作業檔在三個位置都叫 `<代號>.py`（例如 `HK1.py`）：老師的 `HK01/HK1.py`、學生的 `HK1/HK1.py`、助教那邊也一樣；不改名。老師的作業資料夾裡另有一個 `iplot.py`，那是 iPLoT 的墊片（框架產生的，不要改，也不是作業檔）。

## 2. 名字與函式

| 名字 | 型別 | 必要 | 說明 |
|---|---|---|---|
| `REQUIRES` | `list[str]` | 是 | pip 的套件名，第一行、一行寫完。numpy、matplotlib 預設就在；用到 scipy、torch、cv2 就加 `"scipy"`、`"torch"`、`"opencv-python"`（寫 pip 名，不是 import 名） |
| `NAME` | `str` | 是 | 頁面標題 |
| `DOCS` | `list[tuple[str, str]]` | 是 | （顯示名, 網址），只接 http/https；沒有就寫 `DOCS = []`。本機的 PDF 不放這裡，放進 `<代號>Space/` |
| `NOTE` | `str` | 是 | 筆記，純文字；沒有就寫 `NOTE = ""` |
| `DATA` | `Path` | 否 | 資料檔的資料夾，一定是 `Path(__file__).resolve().parent / "<代號>Space"` 這個寫法 |
| `CASES` | `dict[str, dict]` | 是 | 鍵是 case 名（字串常數）；值是參數，`label` 給人看 |
| `compute(case) -> dict` | | 是 | 純計算。可以慢（幾分鐘）；進度用 `print`。回的 dict 自由，只有一個保留鍵：`"text"`（`str`）＝要給人看的文字結果（純文字的作業就只回這個） |
| `draw(fig, run) -> FuncAnimation \| None` | | 是 | 在殼給的 `fig` 上畫（`fig.add_subplot`）。動畫回 `FuncAnimation`；靜態圖回 `None`；純文字作業寫一行 `draw = None` |
| `stats(run) -> list[tuple[str, str]]` | | 是 | 幾個數字；不要就寫 `stats = None` |

「內容可以空，名字不能少」：尾段的 `HOMEWORK = dict(…)` 用到 `DOCS`、`NOTE`、`draw`、`stats`，少一個就是 `NameError`。`DATA` 不在 `HOMEWORK` 裡，沒有資料檔就不用寫。

每個 case 的結果就是三種之一：動畫、一張靜態圖、一段文字（可以同時有圖和文字）。

## 3. 規則與 `--check`

規則有編號。下面這張表與 `coursework.RULES` 是同一份清單：測試把這張表讀出來跟程式比，多一條少一條都會紅。`--check` 每條印成 `✗ R14 第 12 行：不能用 matplotlib 的 Tk 後端（畫面是殼的事）`。

「擋到哪裡」寫的是靜態檢查真的看得到的範圍；看不到的那一半照實寫在那一欄。在 iPLoT 裡跑作業時，`--check` 有問題只在訊息區警告、照樣跑；按「檢查與打包」時，有問題就擋、不打包。例外是 R12 裡不在對照表的 import：那一種只警告（印 `⚠` 開頭），打包也不擋。

| 編號 | 規則 | --check | 擋到哪裡 |
|---|---|---|---|
| R1 | 第一行是 `REQUIRES = [...]`，字串 list 的字面值 | 擋 | 不在第一行、不是 list、裡面不是字串、寫成好幾行 |
| R2 | 第二行是 `import coursework; coursework.ensure(REQUIRES, __file__)` | 擋 | 去頭尾空白、去註解後逐字比 |
| R3 | `NAME` 是字串 | 擋 | 頂層 `NAME = "…"` |
| R4 | `DOCS` 是 `[(顯示名, 網址), …]`，網址 `http://`、`https://` 開頭 | 擋 | 字面值；不是 list、不是兩個字串的 tuple、網址別的開頭 |
| R5 | `NOTE` 是字串 | 擋 | 頂層 `NOTE = "…"`（三引號也算） |
| R6 | 有 `DATA` 的話，剛好是 `Path(__file__).resolve().parent / "<代號>Space"`，那個資料夾在 | 擋 | ast 逐節點比；代號從檔名拿；資料夾不在 |
| R7 | `CASES` 是 dict 字面值：鍵是字串、值是 `dict(…)` 或 `{…}`、`label` 是字串 | 擋 | 鍵不是字串常數（在 iPLoT 裡選 case 要靠它，D128）、值不是 dict、`label` 不是字串 |
| R8 | `compute` 是頂層 `def`，一個參數 | 擋 | 參數個數 |
| R9 | `draw` 是頂層 `def`、兩個參數，或 `draw = None` | 擋 | 同上 |
| R10 | `stats` 是頂層 `def`、一個參數，或 `stats = None` | 擋 | 同上 |
| R11 | 固定尾段三行照樣 | 擋 | `HOMEWORK = dict(…)` 的八個鍵與值逐一比；後兩行逐字比 |
| R12 | 用到的第三方套件都寫在 `REQUIRES` | 對照表裡的擋；其他只警告 | 整個檔的 `import`（連函式裡的）扣標準庫、扣旁邊的 `.py` 與 `coursework`。import 名在殼的對照表裡（`cv2`→`opencv-python` 這種）而 `REQUIRES` 沒寫那個 pip 名：擋。不在對照表的：pip 名可能跟 import 名不同（`import Crypto` 是 `pycryptodome`），只警告、打包也不擋，請老師確認 `REQUIRES` 有寫它的 pip 名（D141） |
| R13 | 不 import `tkinter`、`_tkinter`、`turtle`（含子模組） | 擋 | 所有 `import`、`from … import` |
| R14 | 不用 matplotlib 的 Tk 後端：`backend_tkagg`、`backend_tk`、`FigureCanvasTkAgg`、`NavigationToolbar2Tk` | 擋 | `import` 的模組名以 `matplotlib.backends.backend_tk` 開頭，或檔裡出現那兩個名字 |
| R15 | 不換後端：`matplotlib.use(…)`、`rcParams["backend"]` | 擋 | 呼叫與那個下標的指定 |
| R16 | 不用 pyplot 開圖或拿圖：`show`、`figure`、`subplots`、`subplot`、`gcf`、`gca`、`axes` | 擋 | 追 pyplot 的別名（`import matplotlib.pyplot as X`、`from matplotlib import pyplot as X`、`from matplotlib.pyplot import figure`）；`getattr(plt, "show")` 這種動態寫法看不到 |
| R17 | 不讀鍵盤：`input()`、`sys.stdin` | 擋 | 呼叫 `input`、出現 `sys.stdin` |
| R18 | 不自己開程式或網頁：`os.system`、`os.popen`、`os.startfile`、`os.exec*`、`os.spawn*`、`subprocess`、`webbrowser` | 擋 | 那幾個呼叫；import `subprocess`、`webbrowser` 就擋 |
| R19 | 不 `os.chdir` | 擋 | 呼叫 |
| R20 | 不寫絕對路徑 | 擋 | 字串常數以 `/x/`、`~/`、`X:\`、`X:/`、`\\` 開頭（`"/"` 這種一個字元的分隔符不算）；用拼的路徑看不到 |
| R21 | 不用舊格式的全域 `t2026fscHOMEDIR`、`LF`、`LF_subWIN` | 擋 | 名字出現就擋 |
| R22 | case 之間不共用狀態 | 擋 | `global` 敘述；`nonlocal` 不擋（`draw` 裡的 `update` 用它記狀態是正常寫法，D140）；在函式裡改頂層的 list／dict 看不到 |
| R23 | 寫檔只寫在 `DATA` 底下 | 擋 | `open(…)` 的模式含 `w`、`a`、`x` 而第一個參數是字串常數（會寫到工作目錄）；用變數組出來的路徑看不到 |
| R24 | 不要只指定一個字型 | 擋 | `rcParams["font.family"]`、`rcParams["font.sans-serif"]` 指定成一個字串或只有一個元素的 list |
| R25 | 不定義 iPLoT 的名字：`run`、`on_files`、`on_error`、`TITLE`、`ICON` | 擋 | 頂層的這幾個名字 |
| R26 | 不結束整個程式：`sys.exit`、`exit`、`quit`、`os._exit` | 擋 | 尾段那一行 `raise SystemExit(coursework.main(…))` 以外的這幾個呼叫 |
| R27 | 檔是 UTF-8、語法對 | 擋 | 讀不了、`ast.parse` 失敗（說第幾行） |
| R28 | 作業檔在 Python 3.9 也解析得了（學生的 3.9 才看得到殼的版本提示，而不是語法錯誤） | 擋 | `ast.parse(…, feature_version=(3, 9))` 失敗（說第幾行），句子「這份作業用了 Python 3.10 以後才有的寫法，學生在舊版 Python 上會看不到版本提示」；`feature_version` 是盡力而為，不保證抓到所有 3.10 以後的語法 |

表上沒有、只是約定、`--check` 不管的：

- 跑超過幾秒的 `compute`，每隔一段 `print` 一行進度；下載模型這種，第一次跑要幾分鐘是正常的，`print` 說一聲。
- 圖裡的字用英文比較保險。中文字型殼會設（這台電腦裝了的中文字型加 `DejaVu Sans`），作業檔不用自己設；要自己設就給一串備選（R24）。
- 要幾張子圖就 `fig.add_subplot(2, 1, 1)`。
- 不靠別的全域：`compute`、`draw` 只用自己檔裡定義的東西和參數；case 與 case 之間不共用狀態，要傳東西放在 `run` 裡（R22 擋 `global`；`draw` 裡的 `update` 用 `nonlocal` 記動畫的狀態可以）。

## 4. 套件

- `REQUIRES` 寫 pip 名。對照：`cv2`→`opencv-python`、`PIL`→`Pillow`、`sklearn`→`scikit-learn`、`kan`→`pykan`、`mlx_lm`→`mlx-lm`、`pywt`→`PyWavelets`、`yaml`→`PyYAML`。用到的第三方套件都要寫進去（R12）：import 名在殼的對照表（`coursework.PIP_NAMES`，上面這幾個都在裡面）裡的，`REQUIRES` 沒寫就擋；不在的只警告，自己確認寫的是 pip 名。
- 自己跑 `python3 HK1.py` 時，殼會掃檔案裡的 `import`，漏寫的自動補進 `REQUIRES` 那一行、印一句告訴你；所以**交之前跑一次**。iPLoT 另開的程序不改檔。
- `coursework.ensure` 裝的是缺的那幾個，裝進作業旁邊的 `.venv`，不釘版本。學生用系統的 Python 跑時，旁邊有 `.venv` 就用它重跑同一個檔；沒有 `.venv` 就印出 README 的兩行做法、結束碼 1。**絕不裝進系統的 Python，不用 `pip install --user`**。
- 只有某種機器才有的套件（`mlx-lm` 只有 Apple Silicon）照樣寫進 `REQUIRES`，殼在裝不了的機器上會說清楚。

## 5. 它怎麼被跑

| 怎麼跑 | 殼做什麼 |
|---|---|
| 學生在作業的資料夾 `python3 HK1.py`（系統的 Python；Windows `py HK1.py`，未經實機驗證） | `ensure`：Python 低於 3.10 → 一句話、結束碼 1；旁邊有 `.venv` 而且現在不是它 → 用 `.venv` 的 Python 重跑同一個檔（帶原本的參數），結束碼照它的；重跑的那一個還是不在 venv 裡（`.venv` 壞了）→ 一句話說怎麼重建、結束碼 1，不再重跑；旁邊沒有 `.venv` → 缺套件時印 README 的兩行做法，結束碼 1 |
| `.venv` 的 Python（學生重跑、或 iPLoT 另開） | 缺的裝進這個 venv；學生自己跑時把漏寫的 import 補進 `REQUIRES` 那一行；`main`：先印 `NAME`、`NOTE`、`DOCS`（每個網址一行），再列 case 選號碼（`0` 全部；`--case <名>`、`--all` 不問）；每個 case：`compute` → 印 `text` 與 `stats` → 有 `draw` 就開一個 matplotlib 視窗，關掉才下一個 |
| iPLoT 另開（`CW_FROM_IPLOT=1`，帶 `--case` 或 `--all`） | 不改檔、不問；第一個視窗是文字視窗：`NAME`、`NOTE`、`DOCS`、這個 case 的 `text` 與 `stats`；接著圖的視窗。開不了視窗（matplotlib 壞了）就把同一段文字交給 iPLoT 的訊息區 |

在 iPLoT 裡，老師或助教雙擊作業那一格：對話框列出 case 的號碼（`0` 是全部，取消就不跑），選了之後由課程的 `.venv` 另開程序跑同一個作業檔。iPLoT 自己的程序從不執行作業檔，只用 `ast` 讀它。

## 6. 舊格式 → 新格式對照（舊格式只在「科學計算」裡收；「課程作業」不收）

給寫過舊格式作業（`HKn.txt`）的人。「課程作業」不收規範 v0 的檔（`import hk_page` 的那種）：它看到 `import hk_page` 會說「這是規範 v0 的檔：把 `hk_page` 換成 `coursework`、尾段換成 v2 的三行」。

| 舊格式（`HKn.txt`） | v2 的寫法 |
|---|---|
| `optionList = ['case-1', …]` ＋ `cmdRUN` 裡的 `if optionValue.get()=='case-1'` | `CASES = {"case-1": dict(…, label="…"), …}` |
| `HKn_RUN_CASEk(ich, LF_subWIN)` 裡算的部分 | `compute(case)` |
| `HKn_RUN_CASEk` 裡 `ich==1` 那段（`Canvas`、`FigureCanvasTkAgg`、`CanvasFig.add_subplot`） | `draw(fig, run)`：`fig.add_subplot` 照抄，`Canvas`、`Canvas2.draw()` 刪掉 |
| `ich==0` 那段（`plt.figure`、`plt.show()`） | 刪掉（R16）；但 `ich==1` 那段畫出來是空白、畫壞了（疊錯 axes、蓋掉別的圖）、或比 `ich==0` 少東西（例如 colorbar）時，`draw` 照 `ich==0` 要畫的樣子畫 |
| `print` 出來的結果、Tk 的 `Entry`／`Text` 裡顯示的字 | `compute` 組成一段字放進 `run["text"]` |
| `DocB01`/`DocB02` 裡的網址 | `DOCS`（開的是本機 PDF 的，檔放進 `<代號>Space/`，不寫進 `DOCS`） |
| `###CONTBEGIN … ss="""…""" … ###CONTEND` | `NOTE = """…"""`（原文照抄，行尾的空白與最後多出來的空行可以拿掉） |
| `os.path.join(t2026fscHOMEDIR, 't2026fscSpace', 'HKnSpace', 'x.jpg')` | `DATA / "x.jpg"`（R6、R20、R21） |
| `def HKn():` 那排 8 顆鈕、`cmdHKn_NOTE`、`cmdHKn_SAVEB`、`cmdHKn_SpaceB`、`cmdEditHKn` | 全部刪掉：Edit＝在編輯器開檔、Space＝Finder、筆記＝改 `NOTE` |
| 頂層 `import tkinter as tk`、`FigureCanvasTkAgg`、`plt.rcParams[...]` 指定 Mac 字型 | 刪掉（R13、R14、R24）；字型殼會設 |
| 全域變數在 case 之間傳東西（`global eta, u, v`） | 放在 `run` 裡（R22） |

## 7. 發作業：檢查與打包

1. 先自己跑：`python3 HK1.py`，每個 case 跑過一遍，圖看過。（在 iPLoT 裡雙擊作業那一格也行。）

3. 學生包裡是：`HK1.py`、`coursework.py`、`HK1Space/`（有的話）、`README.txt`（Python 3.10 以上；怎麼跑；只交 `HK1.py`；交之前跑一次）。README 有 macOS 一段與 Windows 一段，Windows 那段標「未經實機驗證」。
