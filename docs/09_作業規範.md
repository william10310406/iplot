# 作業規範（v0，2026-10-16）

一份作業＝一個 Python 檔。寫成這個樣子的作業：學生 `python3 HKn.py` 就能跑、助教在 iPLoT 裡按一顆按鈕就能跑、下學期畫面換成網頁時檔案一個字不用改。老闆發的 HK1–HK12 是舊格式，不受這份約束，助教那邊照舊格式收（`docs/plans/2026-10-16-M6-作業-設計.md` 第 5、7 節）；**從下一份作業起照這份寫**。

這份規範有一個會動的對照物：`modules/科學計算/hk_page.py`（殼）和 `modules/科學計算/examples/` 裡搬成新格式的三份（HK2 靜態圖、HK6 動畫、HK8 純文字）。規範與殼對不上時，以殼為準、回頭改這份。

## 1. 一個檔長什麼樣

```python
REQUIRES = ["numpy", "matplotlib"]              # 用了別的套件就加在這；自己跑一次會自動補
import hk_page; hk_page.ensure(REQUIRES, __file__)   # 缺的在這一行裝好，裝完才往下 import
import numpy as np
from pathlib import Path
from matplotlib.animation import FuncAnimation

NAME = "HK0 範例：一顆球繞圓"                   # 頁面標題；不要叫 TITLE（那是 iPLoT 按鈕的字）
DOCS = [("Uniform circular motion", "https://en.wikipedia.org/wiki/Circular_motion")]
NOTE = """筆記寫這裡。純文字，交之前改這段。"""
DATA = Path(__file__).resolve().parent / "HK0Space"   # 資料檔放這個資料夾；沒有資料檔就刪掉這行
CASES = {
    "case-1": dict(r=1.0, w=1.0, label="半徑 1、角速度 1"),
    "case-2": dict(r=2.0, w=0.5, label="半徑 2、角速度 0.5"),
}

def compute(case):
    """算。純計算、不畫圖、不開視窗；回一個 dict，畫圖和數字都從它拿。"""
    p = CASES[case]
    t = np.linspace(0, 2 * np.pi / p["w"], 200)
    return {"t": t, "x": p["r"] * np.cos(p["w"] * t), "y": p["r"] * np.sin(p["w"] * t)}

def draw(fig, run):
    """畫。在給你的 fig 上畫；要動畫就回傳 FuncAnimation，靜態圖回 None。"""
    ax = fig.add_subplot(111)
    ax.set_aspect("equal"); ax.set_xlim(-2.2, 2.2); ax.set_ylim(-2.2, 2.2)
    ax.plot(run["x"], run["y"], lw=0.8, alpha=0.4)
    dot, = ax.plot([], [], "o")
    def update(i):
        dot.set_data([run["x"][i]], [run["y"][i]])
        return (dot,)
    return FuncAnimation(fig, update, frames=len(run["t"]), interval=30, blit=False)

def stats(run):
    """幾個數字，頁面照順序列；可以不寫。"""
    return [("週期 T", f"{run['t'][-1]:.3f}"), ("點數", str(len(run["t"])))]

# ── 以下不用改 ──
import sys
HOMEWORK = dict(name=NAME, docs=DOCS, note=NOTE, cases=CASES, compute=compute, draw=draw, stats=stats, file=__file__)
def run(app): hk_page.show(app, HOMEWORK)                        # iPLoT 裡按下去
def on_files(app, paths): hk_page.collect(app, paths)            # 把 TronClass 的 zip 拖到這顆按鈕上＝收作業
if __name__ == "__main__" and "core.runner" not in sys.modules:  # 單獨跑
    hk_page.main(HOMEWORK)
```

上半是作業，學生改的；下半六行是固定的，不要動。`hk_page.py` 放在同一個資料夾（發作業時一起給）。

## 2. 五個名字、三個函式

| 名字 | 型別 | 必要 | 說明 |
|---|---|---|---|
| `REQUIRES` | `list[str]` | 是 | pip 的套件名。numpy、matplotlib 預設就在；用到 scipy、torch、cv2 就加 `"scipy"`、`"torch"`、`"opencv-python"`（寫 pip 名，不是 import 名） |
| `NAME` | `str` | 是 | 頁面標題 |
| `DOCS` | `list[tuple[str, str]]` | 否 | （顯示名, 網址），只接 http/https |
| `NOTE` | `str` | 否 | 筆記，純文字 |
| `DATA` | `Path` | 否 | 資料檔的資料夾，一定是 `Path(__file__).resolve().parent / "HKnSpace"` 這個寫法 |
| `CASES` | `dict[str, dict]` | 是 | 鍵是 case 名；值是參數，`label` 給人看 |
| `compute(case) -> dict` | | 是 | 純計算。可以慢（幾分鐘）；進度用 `print`。回的 dict 自由，只有一個保留鍵：`"text"`（`str`）＝要給人看的文字結果（HK8 那種純文字作業就只回這個） |
| `draw(fig, run) -> FuncAnimation \| None` | | 否 | 在殼給的 `fig` 上畫（`fig.add_subplot`）。動畫回 `FuncAnimation`；靜態圖回 `None`；純文字作業不寫這個函式 |
| `stats(run) -> list[tuple[str, str]]` | | 否 | 幾個數字 |

每個 case 的結果就是三種之一：動畫、一張靜態圖、一段文字（可以同時有圖和文字）。

## 3. 不要做的事（殼擋不住、但會壞）

- **不要 `import tkinter`、`turtle`**，不要 `FigureCanvasTkAgg`、`NavigationToolbar2Tk`：在 iPLoT 裡會被擋，單獨跑也不需要。畫面是殼的事。
- **不要 `plt.show()`、`plt.figure()`、`plt.subplots()`**：圖畫在 `draw` 收到的 `fig` 上。要幾張子圖就 `fig.add_subplot(2, 1, 1)`。
- **不要 `input()`**，不要自己開視窗、不要 `os.system("open …")`：Doc 連結寫在 `DOCS`，殼負責開。
- **路徑只能從 `DATA` 或 `Path(__file__)` 出發**：不寫絕對路徑，不寫 `t2026fscHOMEDIR`，不 `os.chdir`。要在磁碟上寫檔（pykan 那種），寫在 `DATA` 底下。
- **不靠別的全域**：`compute`、`draw` 只用自己檔裡定義的東西和參數；case 與 case 之間不共用狀態（HK6 那種用 `global eta, u, v` 的，改成放在 `run` 裡）。
- **圖裡的文字用英文**，或自己設字型時給一串備選（`rcParams["font.sans-serif"] = ["PingFang TC", "Microsoft JhengHei", "Arial Unicode MS", "DejaVu Sans"]`），不能只寫 Mac 才有的那一個。
- **不改下半六行**，不另外定義 `TITLE`、`ICON` 以外的 iPLoT 名字。
- 跑超過幾秒的 `compute` 每隔一段 `print` 一行進度；下載模型（HK9）這種，第一次跑要幾分鐘是正常的，`print` 說一聲。

## 4. 套件

- `REQUIRES` 寫 pip 名。對照：`cv2`→`opencv-python`、`PIL`→`Pillow`、`sklearn`→`scikit-learn`、`kan`→`pykan`、`mlx_lm`→`mlx-lm`、`pywt`→`PyWavelets`、`yaml`→`PyYAML`。
- 自己跑 `python3 HKn.py` 時殼會掃檔案裡的 `import`，漏寫的自動補進 `REQUIRES` 那一行、印一句告訴你；所以**交之前跑一次**。
- `hk_page.ensure` 裝的是缺的那幾個，裝進正在跑的這個 Python（學生：自己的；助教：課程的 `.venv`）。不釘版本。
- 只有某種機器才有的套件（`mlx-lm` 只有 Apple Silicon）照樣寫進 `REQUIRES`，殼在裝不了的機器上會說清楚。
