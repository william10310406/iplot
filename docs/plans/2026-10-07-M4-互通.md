# M4 互通：工作單

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 任何模組都能從面板以外打開（捷徑、一行指令、直接 `python3 iplot.py`），打開後照樣用 `app`；`app.run` 在面板停在下一層時也找得到最上層的模組；`app.run("主控面板")` 叫出面板。

**Architecture：** 核心只改兩處（0.5.1）：`Core.run_by_name` 找不到時退到最上層、＋ 的範本帶「那一小段」。其餘全在兩個工作坊模組：「互通」（`run.py` 自己建 `Core`、用 pywebview 的彈出式視窗當 `View`，跑完同步捷徑與那一小段）與「主控面板」。面板外每次執行是獨立程序，不聽任何 port。

**Tech Stack：** Python ≥ 3.10 標準庫；`lib/` 裡的 pywebview 6.2.1 與 pyobjc（macOS）；pytest、ruff。

**Spec：** `docs/plans/2026-10-07-M4-互通-設計.md`（下稱「設計」）。每個 Task 都要對著設計的對應小節做；這份只寫設計沒定、或實作者不可能自己知道的事。

- 結束碼：0＝模組跑完沒出錯；1＝模組出錯、取消、找不到模組、按了停止；2＝開不起來。

    """tmp/我的 iPLoT/modules/A 是用範本建的模組；with_run_py 時放一個假的 modules/互通/run.py：
