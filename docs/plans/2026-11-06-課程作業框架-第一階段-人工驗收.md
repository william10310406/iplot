# 課程作業 第一階段：人工驗收清單

這份清單是給**不用會寫程式**的人照著按的。每一項寫了「怎麼做」「應該看到什麼」，按完在「結果」勾一個：

- **通過**：看到的跟「應該看到什麼」一樣。
- **不通過**：不一樣。在「備註」寫看到了什麼（截圖更好）。
- **不確定**：看不懂、或跟寫的有點像又不太像。在「備註」寫哪裡不確定。這不是失敗，會有人再看一次。

要記時間的項目，用手機的碼錶就好，寫到「大約幾秒」或「大約幾分鐘」。

**M12 一定要做，不能跳過。** M12 沒做或沒通過，第一階段就不算驗收過。

---

## 準備（執行者做，按的人不用管）

- [ ] iPLoT 從這個分支開得起來：在 worktree 根目錄（`.claude/worktrees/feat-coursework`）有 `lib` 連結，`python3 main.py` 開得出面板。
- [ ] 這台 Mac 上「課程作業」還沒有任何一門課（`modules/課程作業/` 底下只有追蹤進 git 的那幾個資料夾）。
- [ ] 一台 **沒有裝過 python.org Python 的 Mac** 給 M12–M14 用（設計第 10 節第 3 條）。找不到的話，在這台 Mac 新開一個 macOS 使用者帳號，並在 M12 的備註寫「用新帳號做的，裝 Python 那一步沒驗到」。
- [ ] 一支隨身碟，或那台 Mac 能收 AirDrop。
- [ ] 把面板打開，交給按的人。
