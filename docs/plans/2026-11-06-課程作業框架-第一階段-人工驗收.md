# 課程作業 第一階段：人工驗收清單

這份清單是給**不用會寫程式**的人照著按的。每一項寫了「怎麼做」「應該看到什麼」，按完在「結果」勾一個：

- **通過**：看到的跟「應該看到什麼」一樣。
- **不通過**：不一樣。在「備註」寫看到了什麼（截圖更好）。
- **不確定**：看不懂、或跟寫的有點像又不太像。在「備註」寫哪裡不確定。這不是失敗，會有人再看一次。

要記時間的項目，用手機的碼錶就好，寫到「大約幾秒」或「大約幾分鐘」。

**M12 一定要做，不能跳過。** M12 沒做或沒通過，第一階段就不算驗收過。Windows 的 README 未經實機驗證，這份清單不按 Windows。

框中的字（對話框、訊息區、README 的步驟）照 2026-11-07 的程式與 `modules/課程作業/框架/學生README.txt` 寫；如果你看到的字跟這裡有一點不一樣，在備註寫下來。
