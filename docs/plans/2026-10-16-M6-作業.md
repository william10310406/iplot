- `imports_of(file: Path) -> set[str]`（同 `hk_tk.scan_imports`，複製）。`third_party(names, folder) -> set[str]`。
- `dist_for(name: str) -> str`：`importlib.metadata.packages_distributions().get(name, [None])[0]` 或 `PIP_NAMES.get(name, name)`。
- `requires_line(source: str) -> tuple[int, int, str] | None`：`ast` 找頂層 `Assign` 目標 `REQUIRES`、值是 list 字面值；回 `(lineno, end_lineno, 那一行後面的註解或 "")`；多行的 list → 當作沒有（印一句叫人手動加）。
- `fill_requires(file: Path, extra: list[str]) -> bool`：只改那一行：`REQUIRES = ["a", "b", "c"]` 雙引號、原順序＋`extra`，保留 `  # 註解`；其他行一個 byte 不動（讀 bytes、只換那一行的 bytes）；回有沒有改。
- `missing(requires: list[str]) -> list[str]`：`importlib.metadata.distribution(名)` 丟 `PackageNotFoundError` 的（正規化比對）。
- `ensure(requires: list[str], file: str, popen=subprocess.Popen, argv: list[str] | None = None) -> None`：`file` 解析後等於 `Path((argv or sys.argv)[0]).resolve()` 且 `"core.runner" not in sys.modules` → 自動補：`extra = sorted(third_party(imports_of) − 已涵蓋)`（已涵蓋＝`requires` 裡每個 dist 提供的 import 名，用 `packages_distributions` 反查；沒裝的 dist 當作提供同名）→ `fill_requires` → `print(f"已把 {、接} 加進 REQUIRES")`；接著 `missing(requires + extra)`：空 → 回；`NO_INSTALL` → `RuntimeError("缺 x、y；HK_NO_INSTALL 設著，不裝")`；名字不合法 → `RuntimeError`；`popen([sys.executable, "-m", "pip", "install", "--no-input", "--disable-pip-version-check", *（不在 venv 就加 "--user"）, *missing])`，`wait()` 非零 → `RuntimeError(f"裝不了 {…}：在終端機 {sys.executable} -m pip install {…}")`；`importlib.invalidate_caches()`。在 venv ＝ `sys.prefix != sys.base_prefix`。
- `check(file: Path) -> list[str]`：問題清單（空＝過）：`REQUIRED` 缺哪個（頂層名字）；`TAIL` 五行有沒有照樣出現（去頭尾空白比對，順序不拘）；`HOMEWORK = dict(` 那行有沒有 `name=`、`cases=`、`compute=`、`file=__file__`；`FORBIDDEN_IMPORTS`；`FORBIDDEN_CALLS`（`ast.Call` 的 `func` 轉成點名比對）；絕對路徑字串（以 `/Users/`、`C:\`、`/home/` 開頭的字串常數）；`REQUIRES` 漏（`third_party(imports_of) − 涵蓋`）；`DATA = Path(__file__)…` 指的資料夾不存在（只在有 `DATA` 時）。每條一句中文。
- `main` 的 `--check <檔>`：印每條、非零結束碼；全過印「通過」。
