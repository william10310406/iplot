# 課程作業 第一階段：工作單

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 工作坊模組「課程作業」0.1.0 的第一階段：出作業的老師從範本寫一份新作業 → 在 iPLoT 裡選一個 case 看到結果 → 按「檢查與打包」得到學生包 → 學生在一台乾淨的 Mac 上照 README 跑起來。收作業、匯入作業、批次包**不在**這一階段。

**Spec：** `docs/plans/2026-11-06-課程作業框架-設計.md`（下稱「設計」）。每個 Task 對著設計的對應小節做；這份只寫設計沒定的、或執行者不可能自己知道的事。設計與這份對不上時以這份為準，並在回報的裁決清單記一條。

**Architecture：** 全部新東西在 `modules/課程作業/`；框架 `框架/course.py`、作業類型 `作業類型/算完畫圖/type.py`、殼 `作業類型/算完畫圖/coursework.py`，三個都只 import 標準庫。面板程序只執行框架產生的墊片 `iplot.py`，從不執行作業檔；真的跑一律是課程 `.venv` 的子程序。

**Tech Stack：** Python ≥ 3.10 標準庫（殼的頂層要能被 3.9 解析）；pip、venv；numpy、matplotlib（只在子程序與測試裡）；pytest、ruff。

**回報：** `docs/plans/2026-11-06-課程作業框架-第一階段-回報.md`（Task 0 建立，之後每個 Task 補一段：commit、測試數、裁決）。

**人工驗收：** `docs/plans/2026-11-06-課程作業框架-第一階段-人工驗收.md`（M1–M14，給不是工程背景的人照著按）。

## Task 2：讀 `課程.py`、代號、找課與框架

**Files：** Modify `modules/課程作業/框架/course.py`；Create `tests/test_coursework_course.py`。

**Interfaces（`course.py`，頂層只 import 標準庫）：**
- `class CourseError(ValueError)`：訊息一句中文，含「第 n 行」（有行號時）。
- `@dataclass(frozen=True) class Course`：`folder: Path`、`name: str`、`code: str`、`folder_format: str`、`types: tuple[str, ...]`、`packages: tuple[tuple[tuple[str, ...], str, str], ...]`、`only_on: dict[str, str]`。

- `code_number(course, name: str) -> int | None`：名字（檔名去副檔名、zip 名、資料夾名）裡認代號；不分大小寫、數字可以補零；前後是字母時不算（`CHK1` 不是 `HK1`）。

- `course_root(start: Path) -> Path | None`：從 `start` 自己往上，第一個有 `課程.py` 的資料夾。`framework_root(start) -> Path | None`：第一個有 `框架/course.py` 的資料夾。
