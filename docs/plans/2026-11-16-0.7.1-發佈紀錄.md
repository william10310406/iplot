## 沒做的

- 沒有人工驗收：網頁面板的兩個右鍵項目（對話框、訊息區）沒有在真的視窗裡按過；`ui/app.js` 只過了語法檢查與讀程式（本機的瀏覽器預覽沒有拿到權限，沒能載入頁面）。Core、Bridge、tkinter 面板的右鍵選單有自動測試。
- macOS 的垃圾桶「放回」：`mac.py` 的新做法（`NSFileManager.trashItemAtURL`）在本機真的跑過、東西進了 `~/.Trash`，但這台電腦的終端機讀不到垃圾桶資料夾，沒能親眼看到 Finder 的「放回」。已經在用的人要手動複製新的 `modules/作業系統/mac.py` 才有；沒換的話原本的做法（直接搬進 `~/.Trash`）照常，只是要自己把資料夾拖回來。
- Windows 的資源回收筒沿用 `SHFileOperationW`，未經實機驗證。
- 本機試跑時留了四個名字以 `iplot-` 開頭的空資料夾在 `~/.Trash`（`iplot-trash-probe-1116`、`iplot-trash-probe-中文 1116`、`iplot-probe-mac-中文 2`、`iplot-probe-direct`），可以清掉。
