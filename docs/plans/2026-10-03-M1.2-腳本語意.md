# M1.2 腳本語意：課本寫的 Python 腳本不改一行就能當模組

> 這是設計簡報（bounded change），不是逐步計畫。執行者用 superpowers:executing-plans 的紀律（TDD、每步看到紅再綠、台帳），但步驟自己拆。

**目標**：按下按鈕 ＝ 在模組自己的資料夾裡執行 `python3 iplot.py`，只是鍵盤和螢幕換成了視窗。`def run(app)` 留著給想用 `app` 額外能力的人。

**來源**：2026-10-03 老闆使用紀錄——模組裡寫 `input()` 整個視窗凍住、面板沒提示、Terminal 連提示字都沒有；「要用 `app.ask` 才能問問題，感覺無法自由發揮」。老闆裁定：這類問題現在修，不等兩週。

**規格**：`docs/02_重構設計.md`（§7 要加「腳本語意」一段）；設計決定 `docs/03_設計決定.md`。

## 行為（全部在 `core/runner.py`，`run_module` 簽名不變）

執行模組程式碼前把程序環境換成腳本的樣子，執行後（含出錯、含 `SystemExit`）在 `finally` 一定還原：

| 項目 | 執行期間 | 還原 |
|---|---|---|
| `__name__` | `"__main__"`（命名空間裡；`ErrorInfo.module` 仍用 `info.name`） | — |
| 工作目錄 | `os.chdir(info.folder)` | 切回原本的 |
| `sys.path` | `insert(0, str(info.folder))` | 移除那一筆 |
| `sys.argv` | `[str(info.file)]` | 還原 |
| `builtins.input` | `lambda prompt="": app.ask(str(prompt)) or ""`（取消 → 空字串，模組繼續跑；老闆裁定） | 還原 |
| `sys.modules` | 跑完後移除 `__file__` 在 `info.folder` 底下的模組（helper.py 改了下次會重讀，維持「每次都是乾淨的」） | — |
| 沒有 `run` | `handler == "run"` 時不再是錯誤：最外層程式碼就是動作。`handler == "on_files"` 缺少仍回 `MissingHandler` | — |

換的是 `builtins.input`（不是只在命名空間放一個 `input`），所以模組 import 的 helper 裡呼叫 `input()` 也會跳對話框。

`print`、`exit()`、例外、快照、`app.*`：全部不變。

## 測試（`tests/test_runner.py`，用 conftest 的 FakeView／fake_core；每個先紅再綠）

1. `test_input_becomes_dialog`：模組 `x = input("年齡"); print(x)`，FakeView.ask 回 `"10"` → `output == "10\n"`、無 error、view 記到 prompt `"年齡"`。
2. `test_input_cancel_gives_empty`：ask 回 `None` → `output == "\n"`、無 error。
3. `test_input_in_helper_also_dialog`：模組資料夾放 `helper.py`（`def f(): return input("q")`），模組 `import helper; print(helper.f())` → 跳對話框。
4. `test_toplevel_script_without_run_is_ok`：模組只有 `print("hi")` → `ok is True`、`error is None`、`output == "hi\n"`。
5. `test_main_guard_runs`：`if __name__ == "__main__": print("main")` → `output == "main\n"`。
6. `test_cwd_is_module_folder_and_restored`：模組 `open("x.txt", "w").write("1")` → `info.folder / "x.txt"` 存在；跑完 `os.getcwd()` 等於跑前。
7. `test_sibling_import_reloads_after_edit`：`helper.py` 寫 `V = 1`，模組 `import helper; print(helper.V)` → `1`；改成 `V = 2` 再跑 → `2`。
8. `test_sys_argv_is_module_file`：`import sys; print(sys.argv)` → `[str(info.file)]`；跑完 `sys.argv` 還原。
9. `test_env_restored_after_error`：模組 `raise ValueError`，跑完 cwd／`sys.argv`／`builtins.input`／`sys.path` 全部等於跑前。
10. `test_on_files_missing_still_errors`：`run_module(info, app, "on_files", (paths,))` 無 `on_files` → `error.kind == "MissingHandler"`。

既有測試若有「沒有 run 就報錯」的斷言（`test_runner.py`、`test_core.py`、`test_startup.py` 找 `missing_handler`／`MissingHandler`），改成新行為。
