### 設計跟程式對不上的

1. **面板上沒有拖放。** 0.5.1 的網頁面板與 tkinter 面板都沒有「把檔案拖到圖示上」：`ui/app.js` 沒有 drop 的處理，`docs/07` 第 186 行寫著「面板上觸發它的拖放與右鍵還沒做」。`on_files(app, paths)` 現在只有一條路叫得到：「互通」的 `run.py` 從命令列帶參數（`python3 modules/互通/run.py <模組資料夾> <檔或資料夾…>`，參數變成 `Path` 交給 `on_files`，資料夾就是資料夾、zip 就是 zip）。設計裡「拖 `t2026fscSpace/` 到『科學計算』」「拖 TronClass 的 zip 到 `HK5`」兩個手勢在面板上都做不到，核心又不能改；工作單第 7 條的退路（「只收 zip 與檔」）是為「拖資料夾拿到怪東西」準備的，不涵蓋「沒有拖放」。
2. **新格式的學生檔，最上面那幾行在面板的程序裡跑。** 按一個新格式的作業時，核心先在面板自己的程序裡 exec 整個 `iplot.py`（`core/runner.py` 第 72 行），`run(app)` 才叫 `hk_page.show` 另開程序。所以 `hk_page.ensure(REQUIRES, __file__)` 與頂層的 `import numpy`、`from matplotlib.animation import …` 會先在 iPLoT 的 Python 裡跑一次。設計第 8.1 節的 `ensure` 只想到子程序：在面板裡缺套件時，它會用 iPLoT 的 Python 加 `--user` 去裝——裝進系統的 Python；不裝的話頂層的 `import numpy` 失敗，`run` 根本叫不到。這台 Mac 的框架 Python 剛好有 numpy、matplotlib，看不出來；新裝的 python.org Python 沒有。
3. **「互通」會替每個 HK、每個學生各做一個捷徑。** 「互通」的同步是遞迴的（`modules/互通/sync.py` 的 `walk`），12 份 × 50 人就是六百多個 `.app` 在 `modules/互通/捷徑/`；「加上」的候選也會列出學生的 `iplot.py`（按了才改、按之前會列路徑）。核心與「互通」都不改，寫進 `docs/08`。
4. 每按一次，核心會在那個資料夾存 `iplot.py` 的快照（`.history/`），所以 HK 與學生資料夾裡會多一個 `.history/`。不影響執行，寫進 `docs/08`。
5. 面板照名字排：`HK1、HK10、HK11、HK12、HK2、…、HK9`（`core/scan.py` 的 `sorted`，字串排序）。核心不改；資料夾名就是作業名（`collect` 從 `HKn` 這個名字知道是哪一份），不改成 `HK01`。寫進 `docs/08`。
