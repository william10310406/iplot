# 模組導覽列：人工驗收

0.7.0 發版前，在 Mac 上照這份按一遍。自動測試用假的視窗與假的 DOM；另外用真的 pywebview 視窗走過一次（開發用的探針，不進 git），所以這份只列真的要人去按、去看的事。Windows 未經實機驗證，不在這份裡。

## 已經在真的視窗裡看過（2026-11-15）

用 iPLoT 的 `ui/web.py` 與互通的 `run.py` 各開一個臨時的資料夾驗的：

- 面板裡：模組開的頁面最上面有導覽列，高 32px；`pywebview.api` 多了 `_iplot_nav`，模組自己的方法照樣叫得到；淺色與深色都截圖看過。
- 呼叫 `_iplot_nav` 跳到子模組：頁面關掉、模組的 `app.page` 後面的程式先跑完、子模組才開頁面，頁面上有「主控面板」與「↑ 父層」；從子模組跳回父層、跳到沒有頁面的子模組（輸出進訊息區）、跳到主控面板（只關掉這一頁、面板的麵包屑不變）都對。
- `<meta name="iplot-nav" content="off">` 的頁面沒有導覽列。
- 互通：用 `run.py` 開有頁面的模組，頁面有導覽列；呼叫 `_iplot_nav` 之後，另開的程序把子模組跑起來，原本的程序正常結束（結束碼 0）。
- `body` 是橫向 flex 的頁面：導覽列變成左邊一欄（約 160px 寬），只看得到第一個鈕，其餘被捲動區藏住。這是預期的限制，這種頁面要自己放那一行標記。

這些都是用程式叫 `_iplot_nav`，**沒有用滑鼠真的點**：下面每一項都要自己點。

## 要人去按的

準備：用 `python3 main.py` 開面板。要有一個有頁面又有子模組的模組（例如隨附的「工作坊」沒有子模組，可以用 ＋ 新建一個、在 `run` 裡加一行 `app.page("測試", "<h2>頁面</h2>")`，再在它底下用右鍵「在這裡新增下一層模組…」建兩個子模組）。

1. **面板裡跳到子模組**：開那個模組的頁面，點導覽列上的子模組。預期：頁面關掉，面板訊息區出現「<模組> 完成」，再出現子模組的輸出（子模組也有頁面的話，開它的頁面）。面板停在原本那一層。
2. **面板裡跳到父層**：在子模組的頁面上點「↑ 父層」。預期：父層模組跑起來、開它的頁面。
3. **主控面板那一格**：點它。預期：只有這一頁關掉；面板的視窗還在，麵包屑沒變。
4. **視窗到前面**：跳到別的模組之後，新開的頁面視窗在最前面，不是被面板蓋住。
5. **深色模式**：系統設定切到深色，開有導覽列的頁面。預期：導覽列是深色底、字看得清楚，「↑ 父層」是淺紅色。再切回淺色。
6. **滑鼠停著**：停在有說明（docstring）的子模組上，約一秒後出現說明。
7. **橫向 flex 的頁面**：開一個 `body { display: flex }` 的頁面。預期：導覽列變成左邊一欄（已知的限制）；加上 `<meta name="iplot-nav" content="off">` 之後沒有導覽列。
8. **很多子模組**：一個模組底下放十個以上的子模組。預期：導覽列一排橫向捲動，不換行、不超出視窗。
9. **第一次執行要確認的模組**（工作坊裝來、有 `.unconfirmed`）：跳到它時，面板跳出「…是從外面裝進來的，第一次執行前確認…要執行嗎？」的確認；按取消就不跑。
10. **目標被刪掉**：開著頁面時，在 Finder 把導覽列上的某個子模組資料夾丟進垃圾桶，再點它。預期：頁面關掉，訊息區說「找不到模組『…』，可能已經被移除了」，面板重掃。
11. **巢狀的頁面**：兩個模組，A 開頁面、在頁面裡呼叫另一個也開頁面的模組 B。預期：B 的頁面沒有導覽列。

## 從捷徑（互通）開

準備：互通 0.3.0；在面板按一次「互通」做好捷徑。

12. **捷徑開有頁面的模組**：預期：頁面有導覽列；有「主控面板」那一格（最上層剛好一個「主控面板」時）。
13. **從捷徑開的頁面跳到子模組**：預期：另開一個程序（Dock 上 Python 的圖示閃一下，約 1–2 秒），原本那一頁關掉、子模組跑起來；原本的程序結束，Dock 上沒有多出來的圖示。
14. **主控面板那一格**：預期：面板被叫到最前面（沒開的話開一個）。
15. **跳不過去**：把 `modules/互通/run.py` 暫時改名，再點導覽列上的一格。預期：小視窗說「打不開『…』：找不到 run.py…」一句，頁面留著；改回名字。（run.py 在、卻一開始就出錯的情形，這一頁會先關掉，錯誤由新的程序自己跳提示框說。）
16. **行事曆只有一排**：打開行事曆。預期：只有它自己的模組列，沒有導覽列。
17. **「linebot行事曆」兩排**：互通 0.3.0 之後打開它。預期：兩排（它自己的模組列與導覽列）。它的作者加了那一行標記之後只剩一排。
18. **「車車」**：在面板裡開它。預期：導覽列只有「主控面板」一格。

## 其他

19. **跳完之後面板還能用**：做完上面的跳之後，面板上雙擊、右鍵、新增模組都正常；訊息區沒有紅色的錯誤。
20. **更新的順序**：在一份舊的 iPLoT（0.6.3）上裝互通 0.3.0、行事曆 0.1.3，再按「更新」到 0.7.0。預期：捷徑與面板外的執行沒被擋；用舊的互通（0.2.x）更新的話，會被擋下並說明（這是已知的順序問題，見 CHANGELOG 0.7.0〈發佈順序〉）。
