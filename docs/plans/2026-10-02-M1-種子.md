# iPLoT M1「種子」實作計畫

> **給執行代理：** 必要子技能：用 superpowers:subagent-driven-development（建議）或 superpowers:executing-plans 逐一任務執行。步驟用 `- [ ]` 追蹤。沒有 superpowers 的環境就把這份當檢查表，一個任務一個 commit，每一步的「預期」沒出現就停下來回報，不要為了讓它過而多改別的地方。

**目標：** 做出 `docs/02_重構設計.md` 定義的 M1 種子：三層掃描、面板、執行模組、錯誤面板、滑鼠新增模組、右鍵三項、四個隨附模組、測試、CI、文件。驗收 = 設計文件 §12 七條全過。

**架構：** 一個資料夾 `iPLoT/`（就是 `6000_work/iplot`）。核心 `core/` 分三層：底層是 `types`、`text` 兩個資料檔，加上 `meta`、`scan`、`errors`、`runner`、`history`、`create`、`actions` 七個互不相識、不碰 tkinter 的檔案；中層 `app`、`core` 編排；上層 `ui`、`main`。模組是含 `iplot.py` 的資料夾，每次按下在乾淨命名空間重新執行，只拿到一個 `app`。

**技術：** Python ≥ 3.10（python.org 版，內含 tkinter）；使用者端只用標準庫；開發端 `pytest`、`ruff`；CI 用 GitHub Actions macOS runner。

**規格：** `docs/02_重構設計.md`（v1.1）與 `docs/03_設計決定.md`。計畫從規格推出來，執行時兩份都要讀；本計畫的簽名與規格 §6.1、附錄 B 一致，衝突時以本計畫為準並回頭改規格。

## 全域限制（每個任務都隱含這些）

- Python ≥ 3.10；`core/` 與 `main.py` 只 import 標準庫；`tkinterdnd2` 只能在 `ui.py` 載入：`--safe` 時不載入；`ImportError`，或 `TkinterDnD.Tk()` 丟 `RuntimeError`／`TclError`，就退回 `tkinter.Tk`。（檢查點 1 #38）
- 識別字英文；docstring 與畫面文字繁體中文。`core/`（`text.py` 除外）與 `main.py` 的畫面文字一律放 `core/text.py` 的 `T`，這兩處不得出現中文字串常數（docstring 除外）；新模組範本是 `text.py` 的 `TEMPLATE`。`tests/`、`modules/`、`tests/smoke.sh` 不受此限。（檢查點 1 #4）
- 附錄 B 的資料結構全部 `@dataclass(frozen=True)`，放 `core/types.py`；全部型別標註。
- 禁止 `os.system`、字串拼出來的 shell 指令（`subprocess.run` 一律傳 list）、任何裸 `except:`。`except Exception` 只准出現在 `runner.run_module` 與 `load_config`，各加 `# noqa: BLE001` 並寫理由；`Core.report_internal` 只接收例外，本身不需要 `except`。lint 規則明列在 `pyproject.toml`（D29）。（檢查點 1 #1）
- 進入模組程式碼只有一個門：`runner.run_module`，其中的 `exec` 加 `# noqa: S102` 並寫理由。核心其他地方沒有 `exec`。掃描階段（`scan`、`meta`）不執行任何模組程式碼。
- 依賴方向：`ui`/`main` → `core`/`app` → 底層七個。每個檔案能 import 的對象以規格 §6.1 的依賴欄為準，另加 `meta` → `text`、`app` → `actions`、`ui` → `errors`／`actions`；此外只用標準庫。`types`、`text` 誰都可以 import。（檢查點 1 #11）
- 行數預算（`tests/test_budget.py` 強制）：`core/` 扣掉 `ui.py`、`text.py` 的有效行數 ≤ 400；`ui.py` ≤ 150。有效行 = 非空白、非純註解、非 docstring。
- 每個任務結尾 `python3 -m pytest -q` 全綠、`ruff check .` 乾淨才 commit。

## 審查重點

規格沒明說、但真人用起來最可能撞到的五件事；每一條在它所屬的任務裡都有一條測試釘住：

1. **macOS 檔名可能是 NFD。** 資料夾叫「開工」，`os.listdir` 回來的可能是分解形；`app.run("開工")` 用 NFC 比對會找不到。→ Task 4 `test_name_is_nfc`、Task 11 `test_run_by_name_nfd`。
2. **任何人都會用 `print()`。** 雙擊啟動時 stdout 沒人看得到。→ Task 6 `test_print_is_captured`、Task 11 `test_press_logs_output`。
3. **對話框關閉時視窗取得焦點，觸發重掃，而此時一個 press 還在進行**；重畫按鈕會把正在執行的模組的按鈕砍掉。→ Task 11 `test_rescan_deferred_while_busy`。
4. **`config.py` 的值型別錯**（`ROOTS = "modules"`、`HISTORY_KEEP = "20"`）會在啟動時炸。→ Task 11 `test_load_config_wrong_type_falls_back`。
5. **兩個根目錄解析到同一個資料夾**（`["modules", "modules/"]`、`".."` 和一個絕對路徑相同）會出現重複按鈕。→ Task 4 `test_roots_dedupe`。

### Task 6：`runner`，唯一的門

**Files:**
- Create: `core/runner.py`、`tests/test_runner.py`

**Interfaces:**
- Consumes: `errors.from_exception`、`text.T`、`types.Result/ErrorInfo/ModuleInfo`。
- Produces: `run_module(info: ModuleInfo, app: Any, handler: str = "run", args: tuple = ()) -> Result`。流程：讀檔（`utf-8-sig`）→ `compile(src, str(info.file), "exec")` → `ns = {"__name__": info.name, "__file__": str(info.file)}` → 在 `contextlib.redirect_stdout/redirect_stderr` 到同一個 `io.StringIO` 之下 `exec(code, ns)` → `fn = ns.get(handler)`，不可呼叫 → `ErrorInfo(kind="MissingHandler", message=T["missing_handler"].format(handler=handler), file=info.file, line=None, traceback_text="", source="module", module=info.name)` → `fn(app, *args)`。`SystemExit` → `ErrorInfo(kind="SystemExit", message=T["module_exit"], ...)`；`Exception` → `errors.from_exception(exc, info, "module")`；`KeyboardInterrupt` 不接。`duration` 用 `time.perf_counter`；`output` = 擷取到的文字。
