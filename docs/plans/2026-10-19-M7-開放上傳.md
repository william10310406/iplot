- 改位元組造壞 zip（3.12、3.14 一樣）：本地檔頭偏移 6、中央目錄偏移 8 的 bit 0 設起來 → 讀時 `RuntimeError`（加密）；壓縮法（本地偏移 8、中央偏移 10）改成 9 → `NotImplementedError`（Deflate64）；deflate 資料的第一個位元組改成 0xFF → `zlib.error`；中央目錄的原始大小（偏移 24）改大 → 不報錯、讀出來比宣告的少；改小 → `BadZipFile`（CRC）。`zipfile.is_zipfile(b"not a zip")` 是 False。
- `ast.parse("-" * 100000)` 在 3.10、3.12、3.14 都丟 `MemoryError`；`"x = " + "not " * 100000 + "1"` 也是。含 NUL：3.12 起是 `SyntaxError`、`lineno` 是 None；3.10 是 `ValueError`。只有 3.10 報錯的四種：`f"{d["a"]}"` 第 2 行 `f-string: unmatched '['`；`type X = int`、`def f[T](): pass` 第 1 行 `invalid syntax`；`try/except*` 第 3 行 `invalid syntax`。

[remote rejected] HEAD -> main (pre-receive hook declined)`；remote 不在 → 結束碼 128、`does not appear to be a git repository`。`git ls-files -s -z` 一筆是 `100644 <sha> 0\t<路徑>\0`；`git hash-object --no-filters --stdin-paths` 一行一個 sha，跟 index 裡的一樣。

設計沒明說、各段的測試也還沒蓋到、最可能讓用的人出事的六件，各釘一個測試在擁有那段程式的 Task：

- `@dataclass(frozen=True) class File: path: str; size: int; sha256: str`（`path` 相對於模組資料夾、posix、NFC）。
- `@dataclass(frozen=True) class Unpacked: name: str; folder: Path; files: tuple[File, ...]; skipped: dict[str, int]`（`folder` = `staging / name`；`files` 照 `path` 排序；`skipped` 是群組 → 條數，照第一次出現的順序）。
- `skip_group(parts: list[str], info: zipfile.ZipInfo) -> str | None`：照這個順序，第一個對到的就是它的群組（`parts` 已經 NFC，比對一律 casefold）：`parts[0]` 是 `__macosx` → `"__MACOSX/"`；任何一段是 `.venv` → `".venv/"`；任何一段以 `.git` 開頭 → `".git*"`；任何一段在 `SKIP` → `SKIP_SHOWN[那一段]`；最後一段以 `._` 開頭 → `"._*"`；不是目錄、最後一段剛好是 `"Icon\r"` → `"Icon\\r"`；`stat.S_ISLNK(info.external_attr >> 16)` → `"符號連結"`；都不是 → `None`。
- `bad_path(rel: str) -> bool`（`rel` 已去掉目錄條目結尾的那一個 `/`）：空字串；以 `/` 開頭；含 `\`；任何字元的 `unicodedata.category` 是 `Cc`；含 `WINDOWS_CHARS`；任何一段是空的、是 `..`、結尾是 `.` 或空白、`段.split(".")[0].upper() in RESERVED`、`GIT_SHORT.fullmatch(段)`。
- `conflict(entries: list[tuple[str, bool]]) -> str | None`：每一條（路徑, 是不是目錄）拆成段，連同每一個上一層（當目錄）一起，用 NFC＋casefold 當鍵記「原本的寫法、檔或目錄」。同一個鍵：寫法不一樣（只差大小寫，含隱含的資料夾）、一個是檔一個是目錄、兩個都是檔（重複）→ 回那一條的路徑；兩個都是目錄、寫法一樣 → 沒事。
- `inspect(zip_path: Path, staging: Path) -> Unpacked | Refusal`，順序釘死（哪一步不過就回那一句）：
  1. `not zipfile.is_zipfile(zip_path)` → `not_zip`。
  2. `ZipFile(zip_path, metadata_encoding="utf-8")`；這裡丟 `UnicodeDecodeError` → `names_not_utf8`。其他例外不接（交給 receive，Task 7）。
  3. `len(infolist()) > MAX_ENTRIES` → `too_many_entries`（還沒讀任何內容）。
  4. 每一條：NFC；目錄條目去掉結尾一個 `/` 再拆段；`skip_group` 有群組就計數、略過。
  5. 剩下的每一條 `bad_path` → `bad_path`（`path=` 那一條 NFC 之後的完整路徑）。路徑先於形狀：不然 `/m/iplot.py`、`m\iplot.py` 回的是形狀那一句。
  6. 形狀：剩下的最上層剛好一個、而且是資料夾（最上層沒有檔）、有一條檔是 `<名稱>/iplot.py`（檔名剛好小寫）→ 不然 `shape`。
  7. `conflict` → `bad_path`。
  8. 剩下的檔：`> MAX_FILES` → `too_many_files`；宣告的 `file_size` 加總 `> MAX_UNPACKED` → `too_large`。
  9. 一條一條 `z.open(info)`、每次讀 `CHUNK`，寫進 `staging / 名稱 / 路徑`（`open(…, "xb")`），同時算 sha256 與位元組數；讀完的數目 ≠ `file_size` → `refuse("broken", kind="宣告的大小跟內容不一樣")`。不用 `z.read`、不用 `extractall`。
- 例外交給 receive：加密 `RuntimeError`、Deflate64 `NotImplementedError`、壞的 deflate `zlib.error`、CRC 不對 `zipfile.BadZipFile`。
