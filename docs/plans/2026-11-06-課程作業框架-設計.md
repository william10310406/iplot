# 課程作業：設計

2026-11-06。這份是設計（規格），不是工作單；還沒有改任何程式。前一份是 `docs/plans/2026-11-06-課程作業框架-盤點與提案.md`（下稱「盤點」），裡面 6.7 的十四條在 2026-11-06 都有了決定，這份照那些決定寫。

**一句話**：工作坊模組「課程作業」，跟科目無關。主控台上一格「課程作業」，下一層是這台電腦上的每一門課，再下一層是那門課的每一份作業。出作業的老師從範本寫一份作業、在 iPLoT 裡選一個 case 看結果、按一顆鈕打包；學生拿到 zip，照 README 在自己的電腦上跑；助教用「收作業」選 TronClass 下載的檔，一人一格。科學計算是跟著出的範例課程，不必裝。

**前提與限制**
- `core/`、`ui/`、`main.py`、`requirements/` 一行不改。
- `modules/科學計算/` 這學期一個 byte 都不動（凍結在 0.1.1）。舊格式 HK1–HK12 的橋樑留在它裡面，照現狀；這學期助教不用 iPLoT 收作業，所以不做 M6 的人工驗收（D123）。
- 學生端不裝 iPLoT；學生用到的套件裝進作業旁邊的 `.venv`，不裝進電腦本身的 Python（D120 的延續，D130）。
- Windows 未經實機驗證；這份裡寫到 Windows 的地方都是照程式推的。

說明：
- **資料夾不放殼的複本。** 作業資料夾與學生資料夾裡都沒有 `coursework.py`；框架另開程序跑作業時用環境變數 `PYTHONPATH` 指到 `作業類型/算完畫圖/`。框架更新時不會留下舊的殼。殼只在學生包裡有一份複本。代價：在終端機直接 `python3 HK1.py` 跑老師資料夾裡的檔會找不到殼；老師的路是在 iPLoT 裡按（第 6.1 節）。
- **面板程序從不執行作業檔。** 作業資料夾的 `iplot.py` 是墊片，核心執行的是它；墊片只用 ast 讀作業檔（CASES、REQUIRES），真的跑一律是課程 `.venv` 的子程序。盤點第 1 節的兩個延後小事（面板 Python 缺套件時 `ensure` 先交出去結束、`on_files` 跑不到）因此一起消失。
- **墊片只有幾行**：往上找第一個有 `框架/course.py` 的資料夾，把它放進 `sys.path`、`import course`、叫一個函式（`course.homework_button(app, HERE)` 之類）、再從 `sys.path` 拿掉，每次重讀。這跟 `科學計算` 的墊片同一個做法（`modules/科學計算/hk_tk.py:72-92`）。框架更新後墊片不用換。
- **用的時候長出來的不進包**：`.gitignore` 加 `modules/課程作業/*/` 再用 `!` 放回 `框架/`、`作業類型/`、`範例課程/`、`新增一門課/`、`加入範例課程/`。工作坊更新時包蓋上去、包裡沒有的檔留著（`docs/plans/2026-10-24-M8-名字保留-評估.md` 第三節），所以課、`.venv`、學生資料夾在更新後還在。
- **核心包不帶它**：`.gitattributes` 加 `modules/課程作業/ export-ignore`（照 D108 對科學計算的做法），從工作坊發。

### 2.1 框架負責的

| 事 | 第幾階段 |

| 課的 `.venv`：建、列已裝、缺的問一次、一個一個裝、每 5 秒一行進度（從 `hk_tk.py` 的 `ensure_venv`、`installed`、`missing`、`install` 複製過來改，不 import 科學計算） | 1 |
| 面板上的格子：新增一門課、加入範例課程、新增作業、檢查與打包、課那一格、作業那一格；墊片的文字 | 1 |
| 作業那一格按下去：讀 case → `app.ask` 選 → 另開程序（D128） | 1 |

| 匯入作業（學生包 zip → 作業資料夾） | 2 |
| 給沒有 iPLoT 的助教的批次包與名單視窗 | 3 |

框架從不執行學生或老師的檔：判斷一律交給作業類型用 ast 做，真的跑一律是子程序。

### 2.2 作業類型的介面

一種作業類型是 `作業類型/<名字>/type.py`，框架用 `importlib.util.spec_from_file_location` 從檔案載入（是框架自己帶的程式，不是學生的）。名字與函式：

| 名字 | 簽名 | 框架什麼時候用 | 「算完畫圖」 | 階段 |
|---|---|---|---|---|
| `NAME` | `str` | 顯示；`課程.py` 的 `TYPES` 用它指名 | `"算完畫圖"` | 1 |
| `ACCEPTS` | `tuple[str, ...]` | 收作業時哪些副檔名算作業檔（取代 `hk_tk.py` 寫死的 `.py`、`.txt`） | `(".py",)` | 1 |
| `classify(file)` | `-> tuple[str, str \| None]`：`("mine", None)`、`("broken", None)`、`("not-utf8", None)`、`("none", None)` | 收作業、匯入作業、檢查；**只能 ast** | 頂層有 `HOMEWORK = dict(…)` | 1 |
| `cases(file)` | `-> list[tuple[str, str]] \| None`：（名字, label） | 作業那一格按下去，列給人選；`None`＝讀不出來 | ast 讀 `CASES` 的鍵與 `label=` | 1 |
| `requires(file)` | `-> set[str]`（pip 名） | 按作業那一格、課那一格、收作業時看要裝什麼 | `REQUIRES` 那一行，聯集 import 掃描 | 1 |
| `check(file)` | `-> list[Problem]`；`Problem(rule, line, text)` | 作業那一格（只提醒）、檢查與打包（擋）、收作業（標記） | `coursework.check`（第 5 節） | 1 |
| `argv(file, python, case)` | `-> tuple[list[str], dict[str, str]] \| None`；`case` 是名字或 `None`（全部） | 跑；`None` 表示這種作業不是程式，框架改用 `app.open(file)` | `[python, file, "--case", case]`（或 `"--all"`），env 加 `PYTHONPATH`、`CW_FROM_IPLOT=1` | 1 |
| `new(folder, code)` | `-> Path`（要打開編輯的檔） | 新增作業 | 複製 `範本.py` 成 `<代號>.py`、建 `<代號>Space/` | 1 |
| `pack(folder, code)` | `-> list[tuple[Path, str]]`（檔, zip 裡的路徑） | 檢查與打包 | `<代號>.py`、`coursework.py`、`<代號>Space/**`、`README.txt` | 1 |
| `place(bundle, dest, code, space)` | `-> list[Path]`（用掉的檔）；`bundle` 是一個學生交的整包（正本、其他檔與它們在 zip 裡的相對路徑） | 收作業，決定這個學生是這種作業之後；`dest` 已確定在作業資料夾之內、不是連結 | 正本照原 bytes 寫成 `dest/<代號>.py`、複製老師的 Space；回 `[正本]` | 2 |
| `is_placed(folder, code)` | `-> bool` | 覆蓋前、重建前：這個資料夾是不是這種作業放出來的學生 | 有 `<代號>.py` 與墊片 | 2 |

框架給作業類型的保證：路徑都在作業資料夾之內；給人看的句子由框架接；`argv` 的子程序 cwd 是那個檔的資料夾。

**不放進第一版的**：`grade`（自動比對答案，盤點 6.4 的 (iii)；決定 12）。之後要加時是可選的函式，只加不改。

**這個介面接得了的別種作業**（盤點 6.4，只檢查、不做）：只交報告的（`ACCEPTS` 給 `.pdf`、`argv` 回 `None` → `app.open`）；學生附自己的資料檔的（`place` 收到整包、回用掉的檔，框架只把沒用到的列成多交的）。

## 3. `課程.py` 的格式

只放字面值。框架用 `ast.parse` 讀，每個名字用 `ast.literal_eval` 取值，**不 `exec`、不 import**（跟收作業時不執行任何檔同一條線）；Python 3.10 沒有 `tomllib`，所以不用 TOML。認得的名字以外有別的頂層敘述 → 那門課的格子顯示錯誤、說第幾行。

```python
# 這門課的設定。只寫字面值（字串、數字、list、dict、tuple）；改完存檔，面板重掃就生效。
NAME = "科學計算"                  # 課那一格的字；不寫就是資料夾名
CODE = "HK{n}"                     # 作業代號：{n} 是數字。檔名、zip 名裡認這個（HK05 也算 HK5）
FOLDER = "HK{n:02d}"               # 作業資料夾的名字：補零讓面板照數字排（D132）；格子上的字仍是 CODE
TYPES = ["算完畫圖"]               # 這門課收哪幾種作業（第一版只有這一種）
PACKAGES = [                       # 按課那一格時分批問；每批（套件, 給人看的說明, 大小）。不寫＝裝每份作業 REQUIRES 的聯集
    (["numpy", "matplotlib", "scipy"], "HK1–HK8 用的", "約 480 MB"),
    (["torch", "pykan", "PyYAML", "tqdm", "torchdiffeq"], "HK9–HK12 用的", "約 1.1 GB"),
]
ONLY_ON = {"mlx-lm": "apple-silicon"}   # 只有某種機器裝得了的；說明句由框架產生
```

| 名字 | 型別 | 預設 | 檢查 |
|---|---|---|---|
| `NAME` | `str` | 資料夾名 | 非空 |
| `CODE` | `str` | `"HK{n}"` | 剛好一個 `{n}`，其他字元是字母、數字、`_`、`-`；不接 `{n.x}`、`{n!r}` 這種 format 寫法。認的時候不分大小寫、數字前面可以補零 |
| `FOLDER` | `str` | `"HK{n:02d}"` | 剛好一個 `{n}` 或 `{n:0kd}`（k 是 1–4） |
| `TYPES` | `list[str]` | `["算完畫圖"]` | 每個都是 `作業類型/` 底下有的 |
| `PACKAGES` | `list[tuple[list[str], str, str]]` | `[]` | pip 名過 `^[A-Za-z0-9][A-Za-z0-9._-]*$` |
| `ONLY_ON` | `dict[str, str]` | `{}` | 值只接 `"apple-silicon"` |

`新增一門課` 放進去的是只有 `NAME` 的版本（其他用預設），所以一門新課**不用打開這個檔**也能用；要改代號格式或分批裝才打開它。

## 4. 作業檔：規範 v2（`docs/09` 要改的）

### 4.1 改了什麼、為什麼

| v0 | v2 | 為什麼 |
|---|---|---|
| 殼叫 `hk_page.py` | `coursework.py` | 跟科目無關（決定 7）；ASCII 檔名在 Windows 的 zip、TronClass 下載裡不會變亂碼，也是合法的 import 名；跟模組名「課程作業」對得上 |
| 作業檔在三處改名：老師的 `HKn/iplot.py`、學生的 `HKn.py`、助教的 `HKn/<學生>/iplot.py` | 三處都叫 `<代號>.py`；`iplot.py` 是框架產生的墊片 | 不改名就不會搞錯；面板程序不用執行作業檔 |
| 固定尾段 6 行，含 `run(app)`、`on_files`、`"core.runner" not in sys.modules` | 3 行：`HOMEWORK = dict(…)`、`if __name__ == "__main__":`、`raise SystemExit(coursework.main(HOMEWORK))` | 作業檔不再是 iPLoT 模組；`main` 的結束碼不再被丟掉（盤點第 1 節的延後小事） |
| 殼用「上面有沒有 `hk_tk.py`」找 `.venv` | 先看作業檔旁邊的 `.venv`，再往上找有 `課程.py` 的資料夾的 `.venv` | 學生包裡沒有課程資料夾（盤點第 3 節） |
| 在 iPLoT 裡 `--all`，一個接一個 | 在 iPLoT 裡選一個 case（`0` 是全部） | 決定 9 |
| `NOTE`、`DOCS` 沒有顯示 | 純文字顯示 | 決定 9 |
| `--check` 抓得到一半的禁止項 | 每一條都有編號、都擋 | 決定 10、第 5 節 |
| 殼只在 3.10 以上讀得懂 | 殼的頂層在 3.9 也讀得懂（`from __future__ import annotations`，不用 3.10 才有的語法），第一件事檢查版本 | 沒裝 python.org 的 Mac 打 `python3` 會是 Apple 的 3.9，要能說清楚「要 3.10 以上、照 README 第 2 步」，不是一段 traceback |
| 不另外定義 `TITLE`、`ICON` 以外的 iPLoT 名字 | 一個 iPLoT 的名字都不定義 | 作業檔不是模組了，寫了也沒有作用（第 5 節 R25） |

v0 的檔（`modules/科學計算/examples/` 那三份，與這學期沒有發出去過的任何新格式作業）只有 `科學計算` 那個凍結的模組認；「課程作業」不收 v0，`classify` 看到 `import hk_page` 回 `("none", None)`，句子說「這是規範 v0 的檔：把 `hk_page` 換成 `coursework`、尾段換成 v2 的三行」。

## 5. `--check` 的規則與對照表

規則有編號，`coursework.RULES` 與 `docs/09` 第 3 節的表是同一份清單：測試把 `docs/09` 的表讀出來跟 `RULES` 比，多一條少一條都紅（D131）。每條印成 `✗ R14 第 12 行：不能用 matplotlib 的 Tk 後端（畫面是殼的事）`。

「擋到哪裡」寫的是靜態檢查真的看得到的範圍；看不到的那一半照實寫。

| 編號 | 規則 | `--check` 擋不擋 | 擋到哪裡 |
|---|---|---|---|
| R1 | 第一行是 `REQUIRES = [...]`，字串 list 的字面值 | 擋 | 不在第一行、不是 list、裡面不是字串、寫成好幾行 |
| R2 | 第二行是 `import coursework; coursework.ensure(REQUIRES, __file__)` | 擋 | 去頭尾空白、去註解後逐字比 |
| R3 | `NAME` 是字串 | 擋 | 頂層 `NAME = "…"` |
| R4 | `DOCS` 是 `[(顯示名, 網址), …]`，網址 `http://`、`https://` 開頭 | 擋 | 字面值；不是 list、不是兩個字串的 tuple、網址別的開頭 |
| R5 | `NOTE` 是字串 | 擋 | 頂層 `NOTE = "…"`（三引號也算） |
| R6 | 有 `DATA` 的話，剛好是 `Path(__file__).resolve().parent / "<代號>Space"`，那個資料夾在 | 擋 | ast 逐節點比；代號從檔名拿；資料夾不在 |
| R7 | `CASES` 是 dict 字面值：鍵是字串、值是 `dict(…)` 或 `{…}`、`label` 是字串 | 擋 | 鍵不是字串常數（在 iPLoT 裡選 case 要靠它，D128）、值不是 dict、`label` 不是字串 |
| R8 | `compute` 是頂層 `def`，一個參數 | 擋 | 參數個數 |
| R9 | `draw` 是頂層 `def`、兩個參數，或 `draw = None` | 擋 | 同上 |
| R10 | `stats` 是頂層 `def`、一個參數，或 `stats = None` | 擋 | 同上 |
| R11 | 固定尾段三行照樣 | 擋 | `HOMEWORK = dict(…)` 的八個鍵與值逐一比；後兩行逐字比 |
| R12 | 用到的第三方套件都寫在 `REQUIRES` | 對照表裡的擋；其他只警告 | 整個檔的 `import`（連函式裡的）扣標準庫、扣旁邊的 `.py` 與 `coursework`。import 名在殼的對照表裡（`cv2`→`opencv-python` 這種）而 `REQUIRES` 沒寫那個 pip 名：擋。不在對照表的：pip 名可能跟 import 名不同（`import Crypto` 是 `pycryptodome`），只警告、打包也不擋，請老師確認 `REQUIRES` 有寫它的 pip 名（D141） |
| R13 | 不 import `tkinter`、`_tkinter`、`turtle`（含子模組） | 擋 | 所有 `import`、`from … import` |
| R14 | 不用 matplotlib 的 Tk 後端：`backend_tkagg`、`backend_tk`、`FigureCanvasTkAgg`、`NavigationToolbar2Tk` | 擋 | `import` 的模組名以 `matplotlib.backends.backend_tk` 開頭，或檔裡出現那兩個名字 |
| R15 | 不換後端：`matplotlib.use(…)`、`rcParams["backend"]` | 擋 | 呼叫與那個下標的指定 |
| R16 | 不用 pyplot 開圖或拿圖：`show`、`figure`、`subplots`、`subplot`、`gcf`、`gca`、`axes` | 擋 | 追 pyplot 的別名（`import matplotlib.pyplot as X`、`from matplotlib import pyplot as X`、`from matplotlib.pyplot import figure`）；`getattr(plt, "show")` 這種動態寫法看不到 |
| R17 | 不讀鍵盤：`input()`、`sys.stdin` | 擋 | 呼叫 `input`、出現 `sys.stdin` |
| R18 | 不自己開程式或網頁：`os.system`、`os.popen`、`os.startfile`、`os.exec*`、`os.spawn*`、`subprocess`、`webbrowser` | 擋 | 那幾個呼叫；import `subprocess`、`webbrowser` 就擋 |
| R19 | 不 `os.chdir` | 擋 | 呼叫 |
| R20 | 不寫絕對路徑 | 擋 | 字串常數以 `/x/`、`~/`、`X:\`、`X:/`、`\\` 開頭（`"/"` 這種一個字元的分隔符不算）；用拼的路徑看不到 |
| R21 | 不用舊格式的全域 `t2026fscHOMEDIR`、`LF`、`LF_subWIN` | 擋 | 名字出現就擋 |
| R22 | case 之間不共用狀態 | 擋 | `global` 敘述；`nonlocal` 不擋（`draw` 裡的 `update` 用它記狀態是正常寫法，D140）；在函式裡改頂層的 list／dict 看不到 |
| R23 | 寫檔只寫在 `DATA` 底下 | 擋 | `open(…)` 的模式含 `w`、`a`、`x` 而第一個參數是字串常數（會寫到工作目錄）；用變數組出來的路徑看不到 |
| R24 | 不要只指定一個字型 | 擋 | `rcParams["font.family"]`、`rcParams["font.sans-serif"]` 指定成一個字串或只有一個元素的 list |
| R25 | 不定義 iPLoT 的名字：`run`、`on_files`、`on_error`、`TITLE`、`ICON` | 擋 | 頂層的這幾個名字 |
| R26 | 不結束整個程式：`sys.exit`、`exit`、`quit`、`os._exit` | 擋 | 尾段那一行 `raise SystemExit(coursework.main(…))` 以外的這幾個呼叫 |
| R27 | 檔是 UTF-8、語法對 | 擋 | 讀不了、`ast.parse` 失敗（說第幾行） |
| R28 | 作業檔在 Python 3.9 也解析得了（學生的 3.9 才看得到殼的版本提示，而不是語法錯誤） | 擋 | `ast.parse(…, feature_version=(3, 9))` 失敗（說第幾行），句子「這份作業用了 Python 3.10 以後才有的寫法，學生在舊版 Python 上會看不到版本提示」；`feature_version` 是盡力而為，不保證抓到所有 3.10 以後的語法（2026-11-06 加，實作 Task 5 之後） |

不是禁止項、只是約定、`--check` 不管的（`docs/09` 另外列一小段，不放進這張表）：慢的 `compute` 每隔一段 `print` 一行進度；圖裡的字用英文比較保險。

**D135 框架自己給作業檔留版本：作業資料夾裡的 `.版本/`。每次「檢查與打包」成功，存一份打包出去的學生包（整個 zip），永遠不自動刪；每次在 iPLoT 裡按作業那一格，作業檔跟最新一份不一樣就存一份，留最新 20 份。核心不改。**
