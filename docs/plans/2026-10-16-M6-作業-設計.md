## 5. 舊格式執行器：`python hk_tk.py <資料夾> <HKn>`

老闆的 `t2026fsc.txt` 砍到只剩會讓 `HKn.txt` 活的部分，約 60 行：
1. `os.chdir(資料夾)`；`LF = tkinter.Tk()`，`geometry('800x800+100+50')`，標題「<資料夾名> — HKn」；`LF_subWIN = tkinter.LabelFrame(LF)`，`place(relx=0.05, rely=0.1, relwidth=0.9, relheight=0.8)`（跟老闆一樣）。
2. exec 的命名空間 `ns` 裡先放：`__name__`、`os`、`sys`、`tkinter`、`LF`、`LF_subWIN`、`t2026fscHOMEDIR=<資料夾>`、`HAS_DND=False`。`exec(compile(讀 t2026fscSpace/HKn.txt, 檔名, "exec"), ns)`，再 `ns["HKn"]()`。
3. 拿掉的：12 顆固定 HK 鈕、拖放（tkinterdnd2）、`t2026fscEdit`、Terminal、Space 鈕、`CareerHOMEDIR` 那段。HK 檔自己的 8 顆鈕原樣留著——Edit 要 `t2026fscEdit.txt`，沒有就沒反應（跟老闆那邊一樣）。
4. **錯誤要看得到**：exec 或 `HKn()` 丟例外 → `messagebox.showerror` 全文 traceback、stderr 也印，視窗留著；`ModuleNotFoundError` 另外多一行「缺 x：`<python> -m pip install <pip 名>`」。RUN 之後在 Tk 回呼裡炸的（最常見）：`LF.report_callback_exception` 接住，同樣 messagebox＋stderr——沒有這一條，助教只會看到按了 RUN 沒反應。
5. 中文：`sys.stdout.reconfigure(encoding="utf-8")`；學生 `print` 的東西進終端機／面板的訊息區看不到（子程序），寫進 `<資料夾>/執行紀錄.txt`（stdout、stderr 都導過去，每次覆蓋），墊片的 `app.log` 說一句在哪。

**墊片 `iplot.py`**（匯入與收作業時產生，兩層同一份）：

```python
"""按下去用課程的 Python 另開視窗跑這個資料夾的 t2026fscSpace/HKn.txt（舊格式）；把 TronClass 的 zip 拖到這裡＝收作業。"""
import pathlib, subprocess, sys
HERE = pathlib.Path(__file__).resolve().parent
COURSE = next(p for p in HERE.parents if (p / "hk_tk.py").is_file())
sys.path.insert(0, str(COURSE))
import hk_tk

def run(app):
    hk_tk.launch(app, HERE)        # 找 .venv 的 python；沒有就用 sys.executable 並說一句；Popen 之後立刻回來

def on_files(app, paths):
    hk_tk.collect(app, paths, HERE)   # 只有 HKn 那一層有意義；學生資料夾收到檔會說「拖到 HKn 的按鈕上」
```

`launch`：`Popen([python, COURSE/"hk_tk.py", HERE, HK])`，`HK` 從 `HERE/t2026fscSpace/HK*.txt` 的檔名拿；沒有那個檔（例如還沒匯入）就 `app.log` 一句。macOS 從面板開的子程序視窗可能開在後面：墊片 `app.log("視窗開了（在 Dock 上找 Python）")`，要叫到最前面是第 13 節要試的。

## 6. 套件：課程自己的 venv（D96 改版）

- **建**：`sys.executable -m venv <課程>/.venv`（不帶 `--system-site-packages`，乾淨），用 iPLoT 自己在用的那個 python.org Python，tkinter 跟著來。pip：`<venv>/bin/python -m pip install --no-input --disable-pip-version-check …`（Windows `Scripts\python.exe`）。
- **課程套件**（從 12 份掃出來的，寫死在 `hk_tk.py` 的 `COURSE_PACKAGES`）：numpy、matplotlib、scipy、Pillow、opencv-python、pandas、scikit-learn、torch、pykan、torchdiffeq、PyWavelets；`mlx-lm` 只在 `sys.platform == "darwin" and platform.machine() == "arm64"` 才列。按「科學計算」→ `app.confirm("要裝課程套件嗎？numpy … torch、pykan，幾百 MB、幾分鐘，裝進 科學計算/.venv")` → 只裝缺的（先用 venv 的 Python 列 `importlib.metadata.distributions()`）→ pip 的輸出一行一行讀，每 5 秒 `app.log` 最後一行 → 完成一句。
- **import 名 → pip 名**：`cv2`→opencv-python、`PIL`→Pillow、`sklearn`→scikit-learn、`kan`→pykan、`mlx_lm`→mlx-lm、`pywt`→PyWavelets、`yaml`→PyYAML、`bs4`→beautifulsoup4、`skimage`→scikit-image、`dateutil`→python-dateutil；表上沒有的當作同名。

**誰是一個學生**（2026-10-17 再審；`hk_tk._students_in`）。TronClass 下載下來，一個學生就是一個 `.zip` 或一個 `.txt`（交 `.txt` 的就是 `HKn.txt`；交 `.zip` 的裡面是 `HKn.txt` 加備份、自測）。標準樣本是 `tests/fixtures/科學計算/` 的 `HK1.txt`、`HK1_threebody_backup.txt`：備份也是完整的舊格式 HK1，`classify` 分不出正本，正本只能靠檔名認。四條：

3. **資料夾裡的 zip 要解。** 收作業時選進來的資料夾裡的 zip 也解在原地（副檔名不分大小寫），解開的 zip 裡再有 zip 再解一次，第三層不解；匯入作業包照舊不解（老師 Space 裡的 zip 不動）。
4. **其他不猜，但看得到。** 收完的名字裡有 `HK<n>` 的，句尾提示「名字看起來是檔名不是學生」；正本直接放在那一樣底下、而多交的裡有子資料夾或子 zip 裡認得的作業（`下載/HK1.txt` 沒改名、旁邊是別人的 zip）→ 句尾提示「`下載` 直接放著一個 `HK1.txt`，所以整個資料夾被當成一個人」。已知收不對、不修的：`全班/B1/HK5.txt` 只有一個學生的全班資料夾選 `全班` → 叫 `全班`（跟 `王小明/作業/HK5.txt` 長得一樣）；名字只是含著 `HKn` 的全班 zip 裡只有一個人（`HK5-重交.zip/B1/HK5.txt`）→ 叫 `HK5-重交`。

## 8. 沒有 iPLoT 的批改（批次模式，D98）

`python hk_tk.py --batch HK5.zip --kit <老師的 t2026fscSpace> [--out 資料夾] [--venv 資料夾]`：
- 同一個 `collect` 整理到 `HK5_收件/`（預設在 zip 旁邊），`HK5Space/` 從 `--kit` 拿。
- venv 預設在 zip 旁邊的 `科學計算-venv/`（幾個 HK 共用），缺的套件裝進去；沒有網路就只報。
- 一個 Tk 視窗：全班名單（Listbox）、每列後面標語法錯／缺套件，雙擊或按「開」→ 同一個執行器另開視窗。不用瀏覽器、不用 server：舊格式本來就是 Tk 的世界，批次模式跟它一致、完全離線。
- Windows：tkinter、TkAgg、venv、torch 都有；mlx-lm 沒有（HK9 看不了，名單上標出來）。
- 名單對新格式的學生一樣：點了就用 venv 的 Python 跑他的 `iplot.py`。

## 8.1 新格式的殼 v0：`hk_page.py`（M6a.1）

規範（`docs/09`）定的六行固定尾段只叫四個東西，v0 把這四個做出來，**畫面用 matplotlib 自己的視窗**，網頁留給 v1：

- `ensure(requires, file)`：`importlib.metadata.distribution` 找得到就不碰；缺的用**正在跑的這個 Python** 裝（`[sys.executable, "-m", "pip", "install", "--no-input", …]`；不在 venv 裡就加 `--user`）——學生那邊是他自己的 Python，助教那邊子程序本來就是課程的 `.venv`，所以不用知道 iPLoT 在哪、不碰 `lib/`。學生自己跑自己的檔（`file` 解析後等於 `sys.argv[0]`）時：`ast.walk` 掃 import、扣標準庫與旁邊的 `.py`、對照表查 pip 名（`importlib.metadata.packages_distributions()` 反查已裝的，沒裝的當同名）、**只改檔案裡 `REQUIRES = […]` 那一行**（保留後面的註解），印一句。別的情況（助教那邊、批次、`import` 進來的）絕不改檔。pip 名過 `^[A-Za-z0-9][A-Za-z0-9._-]*$`；`HK_NO_INSTALL=1` 不裝只報。頂層只 import 標準庫；numpy、matplotlib 在用到的函式裡才 import（`import hk_page` 發生在 `ensure` 之前）。
- `main(hw)`：`reconfigure` stdout；終端機列出 `CASES`（編號、名字、label），`input` 選一個，`0` 全部，`--case <名>` 直接跑；每個 case：`run = compute(case)` → 印 `run.get("text")` 與 `stats(run)` → 有 `draw` 就 `fig = plt.figure(figsize=(7, 6))`、`ani = draw(fig, run)`（`ani` 要抓著不然動畫停）、`plt.show()`，關掉視窗才下一個。例外印 traceback 全文、不中斷下一個 case。
- `show(app, hw)`（在 iPLoT 裡）：往上找課程資料夾（有 `hk_tk.py` 的）→ `.venv` 的 Python（沒有就 `sys.executable`＋`app.log` 一句）→ `Popen([python, hw["file"]])`，cwd 是檔案的資料夾 → `app.log("視窗開了")`，立刻回來。跟舊格式的墊片同一條路，畫面同一種。
- `collect(app, paths)`：找課程資料夾、`import hk_tk`、`hk_tk.collect(app, paths, 檔案的資料夾)`。收作業只有一份程式。
- `python hk_page.py --check <檔>`：規範第 7 節那串靜態檢查，印報告、非零結束碼表示不過。`hk_tk.collect` 對新格式的檔也用它。
- 殼的 v0→v1 升級只換 `main` 與 `show` 的畫面（預先畫格、網頁、`app.page`），四個函式的簽名與 `HOMEWORK` 的鍵不變；規範第 8 節寫死了這一點。

`examples/HK2.py`、`HK6.py`、`HK8.py`：照 `docs/09` 第 6 節的對照表從老闆的 12 份搬，各帶 `HKnSpace/` 要的檔（HK2、HK6、HK8 都不用資料檔）。它們是規範的驗證，也是老闆下一份作業的起點：`cp examples/HK6.py HK13/iplot.py` 改起。

## 10. 安全（`docs/07` 第 7 節要補的）

- 信任邊界：助教按下一份作業＝在自己的電腦上執行學生的任意程式碼，跟老闆現在把學生的 `HKn.txt` 放進 `t2026fscSpace/` exec 完全一樣；pip 裝掃出來的套件是同一個邊界，收作業那一次 confirm 就是問。
- 子程序用 `.venv` 的 Python，不碰系統 Python、不碰 iPLoT 的 `lib/`；pip 名過字元集合，不經 shell。

- 匯入、收作業都不執行任何學生或老師的程式碼（只 `ast.parse`）。

## 11. Windows、Linux
