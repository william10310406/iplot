## 修正 1：input() 按取消 → 丟 EOFError（推翻 D47 的「取消 → 空字串」）

現況：`runner._dialog` 的 `ask` 回 `app.ask(...) or ""`。課本最常見的驗證迴圈 `while True: try: n = int(input()) except ValueError: continue` 按取消永遠出不去，只能強制結束 iPLoT。這違反 M1 的承諾「壞了要說哪裡壞」。

改成：`app.ask` 回 `None` 時 `raise EOFError(T["input_cancelled"])`，`T` 加一條 `"input_cancelled": "在提問時按了取消"`。這就是真的 `input()` 在鍵盤關掉（Ctrl-D）時的行為，跟 D47「就像 `python3 iplot.py`」一致。不接住它：`from_exception` 會給 kind `"EOFError"`、檔案與行號指到模組裡呼叫 `input()` 的那一行，面板顯示「模組『X』第 N 行出錯：EOFError，在提問時按了取消」。模組自己 `except EOFError` 可以接。`app.ask` 不變，照舊回 `None`。

測試（`tests/test_runner.py`，用現有的 `fake_core.view.answer = None` 表示取消）：
- 把 `test_input_cancel_gives_empty` 改成 `test_input_cancel_raises_eoferror`：未接住 → `r.ok` 是 False、`r.error.kind == "EOFError"`、`r.error.line` 指到 `input()` 那一行、`r.error.message == T["input_cancelled"]`。
- 新增 `test_validation_loop_exits_on_cancel`：腳本是 `while True:\n    try:\n        n = int(input("數字"))\n        break\n    except ValueError:\n        pass\n`，`answer = None`，`run_module` 要回來（不是卡死），`fake_core.view.asks` 長度是 1。
- 新增 `test_module_can_catch_cancel`：`try:\n    x = input("q")\nexcept EOFError:\n    x = "預設"\nprint(x)\n` → `r.ok`、output 是 `"預設\n"`。
- `test_input_in_helper_also_dialog` 等其他 input 測試不應受影響。

## 修正 2：exit() / sys.exit(0) / quit() 當正常結束

現況：runner 接 `SystemExit` 一律變錯誤，message 是 `T["module_exit"]`「模組呼叫了 exit()，已忽略」。初學者常在腳本結尾寫 `exit()`，而 `python3 iplot.py` 跑這種腳本是正常結束，狀態 0。

改成：`exc.code` 是 `None` 或 `0` → 不是錯誤，`r.ok` 為 True、`r.error` 為 None（輸出照常收進 `Result.output`）。其他值 → 還是錯誤，kind `"SystemExit"`，message 改成 `T["module_exit"] = "模組以 exit({code}) 結束"`（用 `.format(code=exc.code)`；code 是字串時照 Python 的做法把字串當訊息，也就是 `exit("壞了")` 顯示「模組以 exit(壞了) 結束」，不用特別處理）。`KeyboardInterrupt` 照舊不接。

測試：
- `test_exit_is_error_not_fatal` 改成用 `exit(1)`，斷言 kind == `"SystemExit"`、message == `T["module_exit"].format(code=1)`、檔案行號照舊。
- 新增 `test_exit_zero_is_ok`：三個腳本 `print("a")\nexit()\n`、`import sys\nprint("a")\nsys.exit(0)\n`、`print("a")\nquit()\n` 都 `r.ok`、`r.error` 是 None、output 是 `"a\n"`。
- 新增 `test_exit_after_exit_env_restored`：`exit()` 之後 cwd、`sys.argv`、`builtins.input`、`sys.path`、`sys.dont_write_bytecode` 都還原（參考 `test_env_restored_after_error` 的寫法）。
