# M5 行事曆：工作單

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 工作坊模組「行事曆」0.1.0：打開就是行事曆，每天四欄加圖片，一天一個資料夾，產生本機網頁（綜合、年、月、日）；打開「公開」的日子另外產生一份可以放上網路的 `發佈/`；上方模組列叫得到任何模組，任何模組 `app.run("行事曆")` 叫得到它，小視窗的回去鈕回到它（D89–D93）。

**Architecture：** 核心、`ui/`、`main.py`、`requirements/` 一行不改。新東西全在 `modules/行事曆/`：`iplot.py`（程序與 `Api`）、`diary.py`（資料）、`pages.py`（網頁；設計叫它 `site.py`，見「設計要確認的事」第 3 條）、`photos.py`（圖片）、`page.html`（畫面）。「互通」只改回去鈕（`run.py`、`popup.py`、`popup.html`，D93），以及確認之後的小視窗修正（第 2 條）。行事曆的頁面只在它自己經「互通」`run.py` 另開的程序裡開（`IPLOT_CALENDAR=1`、`.pid`）。

**Tech Stack：** Python ≥ 3.10 標準庫（`calendar`、`datetime`、`html`、`json`、`base64`、`struct`、`zlib`、`threading`、`subprocess`、`unicodedata`）；`lib/` 裡的 pywebview 6.2.1 與 pyobjc（macOS）；`sips`、`ps`（macOS）；pytest、ruff。

**Spec：** `docs/plans/2026-10-14-M5-行事曆-設計.md`（下稱「設計」，已定案、不改）。每個 Task 都要對著設計的對應小節做；這份只寫設計沒定、或實作者不可能自己知道的事。設計跟程式對不上的地方列在下一節，不代為改設計；每個 Task 照「建議怎麼改」寫，依賴它的步驟標「（待確認第 N 條）」並附一行退路。

**第 2 條：行事曆開著時小視窗 1 秒後會冒出來；關它、按「停止」、或一次 `app.log`／`app.open` 出錯，都會結束整個行事曆。**
- 設計怎麼說：第 3.1 節在自己的程序裡 `app.page`，頁面整天開著；第 4 節「換資料夾」承認「小視窗會先跳出來」；第 2 節「互通」除了回去鈕以外不改。沒有一處說會多出第二個小視窗、關它會關掉行事曆。

- `add_image(folder: Path, name: str, data: bytes, *, run=subprocess.run, platform=sys.platform) -> tuple[str | None, str | None]`：回 `(存成的檔名, 問題那一句或 None)`。`len(data) > MAX_BYTES` → `(None, TOO_BIG)`；副檔名不在 `SUFFIXES` → `(None, NOT_IMAGE)`；否則 `folder.mkdir(parents=True, exist_ok=True)`（一天的第一樣東西可能是照片，設計第 4 節「第一次存東西時才建立」；`photos` 不 import `diary`，所以自己建）→ `clean_name` → `unique_name` → 先寫 `.<name>.tmp-<pid>` 再 `os.replace`；`.heic`／`.heif` 且 `platform == "darwin"` → `to_jpeg`，轉不出來回 `(檔名, NO_JPEG)`（原檔留著）；macOS 以外 HEIC 不轉、回 `(檔名, NO_JPEG)`。
- `to_jpeg(path: Path, run=subprocess.run) -> Path | None`：`run(["sips", "-s", "format", "jpeg", str(path), "--out", str(path.with_suffix(".jpg"))], capture_output=True, check=False, timeout=60)`；輸出檔存在且 returncode 0 才回它；`OSError`／`SubprocessError` 回 None。
- `shrink(src: Path, dst: Path, run=subprocess.run) -> bool`：`["sips", "-Z", "1600", str(src), "--out", str(dst)]`，同上判斷。
- `strip_metadata(src: Path, dst: Path) -> None`：純 Python，照副檔名／檔頭：JPEG（`FF D8`）逐段讀 marker，丟掉 `0xFFE1`（APP1：EXIF、XMP）與 `0xFFED`（APP13：IPTC／Photoshop），其餘段原樣寫，到 SOS（`0xFFDA`）之後整段複製到結尾；PNG（八位元組簽章）逐 chunk 讀 `長度(4) 型別(4) 資料 CRC(4)`，丟掉 `eXIf`、`tEXt`、`iTXt`、`zTXt`，其餘原樣；GIF（`GIF8`）整個複製；其他 → `ValueError("不是 JPEG、PNG、GIF")`。先寫暫存再 `os.replace`。
- `public_copy(src: Path, dst: Path, *, run=subprocess.run, platform=sys.platform) -> None`：`darwin` 且是 JPEG／PNG → `shrink(src, 暫存)` 成功就對暫存 `strip_metadata`，失敗就對 `src` 直接 `strip_metadata`；GIF 與 macOS 以外一律只 `strip_metadata`；`dst.parent` 自己建。
- `thumbnail(src: Path, dst: Path, run=subprocess.run) -> bool`：`["sips", "-Z", "320", …]`——**只在 Task 0 Step 4 不過時才寫**，否則不加。
