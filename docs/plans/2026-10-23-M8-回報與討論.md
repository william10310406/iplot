統計的鍵（順序也是 `summary` 列的順序）：`"路徑"`（每一個被 `path_label` 換掉、結果含 `<HOME>`、`<PATH>` 或 `<檔名已遮蔽>` 的路徑算 1，第 6 步換掉的檔名算 1；`<IPLOT>/…`、`<PYTHON>/…`、`<模組:X>/第一層檔名`、原樣回來的（以 `<` 開頭）不算；一個路徑只算一次，不數記號）、`"使用者名稱"`、`"疑似學號"`、`"電子郵件"`、`"原始碼"`（拿掉的 frame 數）、`"下一層模組"`。

**做法，照這個順序**（第 1–6 步的路徑規則不處理以 `<` 開頭的路徑；第 7–10 步只換 `<…>` 記號**之外**的字：先用 `TOKEN = re.compile(r"<(?:HOME|PATH|USER|EMAIL|IPLOT|PYTHON|疑似學號|下一層模組|檔名已遮蔽)>")` 把字切開，只對記號之間的段落做；**每一個要換的字串（每一個 secret、信箱、學號、每一個使用者名稱）換之前都重新切一次**（前一個換出來的記號也要擋住：帳號叫 `User` 又有 `user` 的電腦、帳號叫 `email` 的電腦，不能換出 `<<USER>>`）。`<IPLOT>/core/runner.py`、`<模組:…>/hk_tk.py` 這種標籤裡留下來的名字**照樣換**：帳號名寧可多遮——CI 的 macOS、Linux 帳號就叫 `runner`，那裡的 `<IPLOT>/core/runner.py` 會變成 `<IPLOT>/core/<USER>.py`，這是對的。這兩條是冪等的關鍵）：

1. **frame**：一行一行看；frame 那一行是 `^(?P<lead>(?:[ \t]*\|)?[ \t]*)File "(?P<path>.*)", line (?P<n>\d+)(?P<tail>[^\n]*)$`（`path` 是貪婪的：路徑裡有 `"` 也認得；`lead` 認得 `ExceptionGroup` 的 `  | `；`tail` 可以是空的——`SyntaxError` 的位置那一行沒有 `, in f`）。`path` 換成 `path_label(path, ctx)`（下面）。frame **安全**的條件：換過之後以 `<IPLOT>/core/`、`<IPLOT>/ui/`、`<IPLOT>/lib/`、`<IPLOT>/main.py`、`<PYTHON>/` 開頭，或以 `<IPLOT>/<USER>/`、`<IPLOT>/<USER>.py` 開頭（帳號名剛好是 `core`、`lib`、`main` 的電腦，第一次遮完的標籤會變成這樣；不認的話遮第二次會把留著的原始碼拿掉，不冪等），或原本就是 `<frozen …>`（`<string>`、`<stdin>` **不算**安全：`eval`／`exec` 一個字串出 `SyntaxError` 時，底下就是那個字串的內容）。不安全的 frame：**前綴**＝`lead` 裡到 `|` 為止（含 `|`）那一段，沒有 `|` 就是空字串；它底下「以同一個前綴開頭、前綴之後的空白比 `lead` 裡前綴之後的空白多、去掉空白之後不是 `File "` 開頭」的連續幾行（原始碼與 `~^` 的標記）全部拿掉，換成一行 `lead + "  （原始碼已略過）"`；一行都沒有（`<frozen …>`、底下就是另一個 frame）就不加。
2. **引號裡的路徑**：先找「引號後面緊接著絕對路徑開頭」的：`(?P<q>['"])(?P<p>(?:/|[A-Za-z]:[\\/]|\\\\)(?:(?!(?P=q))[^\n])*)(?P=q)`（`Can't …` 的撇號不會把引號配錯；路徑裡可以有空白）；再找其他的 `'[^'\n]*'|"[^"\n]*"`，裡面含 `/` 或 `\`、不以 `<` 開頭、不含 `://` 的。都換成 `path_label`（引號留著）。
3. **括號裡的絕對路徑**（`ImportError` 的 `cannot import name 'g' from '工具' (/…/My Drive/…/工具.py)`）：`\((?P<p>(?:/|[A-Za-z]:[\\/]|\\\\)[^()\n]*)\)` 整段（可以有空白）換成 `(` + `path_label` + `)`。
4. **沒有引號的已知開頭**：`ctx.iplot`、`ctx.pythons`、`ctx.module`、`ctx.home`（長的先比；不分大小寫；`/` 與 `\` 兩種寫法都試），後面緊接分隔符號、空白、引號、`)` 或字串結尾的（以分隔符號為界）：從開頭一路吃到同一行裡、不跨過引號、`(`、`)`、`<`、`>` 的**最後一個** `/` 或 `\`（中間可以有空白：`OneDrive - 國立臺灣大學`、`作業 HK5`、`我的 iPLoT`），最後一段到空白、引號、`)` 為止，整段當一個路徑換成 `path_label`：`<開頭>(?=$|[/\\\s'")])(?:[^'"\n()<>]*[/\\])?[^\s'"()<>/\\]*`。
5. **沒有引號的其他絕對路徑**：前面的字只看 ASCII（`(?<![A-Za-z0-9_>.:~/\\-])`；不能用 `\w`：中文字也算 `\w`，`找不到/Volumes/…` 會漏）。POSIX `/段/段…`（至少兩段）、Windows `(?<![A-Za-z0-9])[A-Za-z]:[\\/]…`（反斜線與正斜線都認：tkinter 的檔案對話框在 Windows 回 `D:/…`；前面不能是字母，`https://` 才不會中）、UNC `\\\\…`；後半段跟第 4 步一樣延伸到同一行最後一個分隔符號，換成 `path_label`。
6. **`SyntaxError` 訊息尾巴的檔名**：`\((?P<f>[^()\n/\\<]+(?:\([^()\n/\\<]*\)[^()\n/\\<]*)*), line (?P<n>\d+)\)`（檔名裡可以有一層括號：瀏覽器重複下載的 `王小明 (1).py`；不要用 `[^\n]+?` 或錨在行尾——`'(' was never closed (x.py, line 1)` 會被吃掉前半句），`f` 不是 `iplot.py`、`config.py`、`main.py` 就換成 `(<檔名已遮蔽><副檔名>, line N)`。
7. **`ctx.secrets`**：每一個（不分大小寫）換成 `<下一層模組>`。排在路徑規則**後面**：路徑先整段變成標籤，名字就跟著不見了；放在前面的話，路徑被 `<下一層模組>` 切斷，第 4、5 步不跨 `<`、`>`，後面的檔名會漏。
8. **電子郵件** `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}` → `<EMAIL>`（排在使用者名稱前面：信箱裡常常有帳號名）。
9. **疑似學號**：`(?<![A-Za-z0-9])(?:[A-Za-z]\d{7,9}|\d{8,10})(?![A-Za-z0-9])` → `<疑似學號>`。前後只看 ASCII：`王小明B11201234` 要中（`'明'.isalnum()` 是 True，照字面的「不是字母數字」會漏）。排在使用者名稱前面：帳號名是中文的電腦（`王小明`），`王小明B11201234` 才不會遮第二次又變一個樣子。
10. **使用者名稱**：`ctx.users` 裡 3 個字以上的，前後不是 ASCII 英數字（`(?<![A-Za-z0-9])…(?![A-Za-z0-9])`，不分大小寫）→ `<USER>`。少於 3 個字的不換。

`path_label(p, ctx) -> str`（模組層的函式，也給測試直接用）：先把 `\` 當 `/` 看、**連續的分隔符號當一個**（Windows 上 `OSError` 的訊息是 repr，反斜線是兩個：`'C:\\\\Users\\\\…'`）、不分大小寫比，**以分隔符號為界**（家目錄 `<HOME>` 不能吃到另一個名字比較長的家目錄，例如 `/Users/laoban` 與 `/Users/laobanxyz`——這個例子只寫在測試裡）。副檔名 `ext` = 最後一段的 suffix，符合 `\.[A-Za-z0-9]{1,8}` 才留，否則 `""`。照順序：
- 以 `<` 開頭：原樣。
- 在 `ctx.iplot` 底下的 `core/`、`ui/`、`lib/`、`main.py`、`config.py`：`<IPLOT>/` + 相對路徑（用 `/`）。

- 在 `ctx.module` 底下：相對路徑只有一段 → `<模組:{module_name}>/` + 那一段；更深 → `<模組:{module_name}>/.../<檔名已遮蔽>{ext}`。
- 等於家目錄 → `<HOME>`；在家目錄底下 → `<HOME>/.../<檔名已遮蔽>{ext}`。
- 其他絕對路徑（`/…`、`X:\…`、`X:/…`、`\\…`）→ `<PATH>/.../<檔名已遮蔽>{ext}`；相對路徑 → `.../<檔名已遮蔽>{ext}`。
