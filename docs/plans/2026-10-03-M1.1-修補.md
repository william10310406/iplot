## Global Constraints

照 `docs/plans/2026-10-02-M1-種子.md` 的「全域限制」全部沿用，特別是：

- 分支：從 `main`（`08e2d4f`）開 `m1.1`，做完依 D30 合併回 `main` 再打 tag `v0.1.1`。

## Review Focus

規格沒明說、但真人用起來最可能撞到、而本計畫的測試沒釘住的五件事：

1. **`logs/` 寫不了時，面板那句「詳細內容在 logs/iplot.log」是假的。** 合理期待：面板仍報核心錯誤，不因記錄檔失敗而少報。→ 本計畫接受這句文字不精確（改文字要動 `core_error` 鍵，M2 再議）。
2. **`ROOTS = []`**：型別合法，面板上一組都沒有、連 ＋ 都沒有，使用者沒有任何滑鼠路徑可以新增模組。→ 本計畫不處理；記進 §5。
3. **`EDITOR = ["code"]`（沒有 `{file}`）**：型別合法，每次開檔都只啟動編輯器不開檔案。→ 本計畫不處理（這是使用者的設定選擇，`actions.edit` 的行為可預期）。
4. **雙擊 `iPLoT.command` 時 `python3` 是 Apple 的 shim 且沒裝 Command Line Tools**：macOS 會跳對話框，`main.py` 根本沒跑到。→ 本計畫處理不了，README 已說用 python.org 版本。
5. **Python 3.10 但沒有 tkinter（Homebrew 版）**：版本防線過了，`import tkinter` 才炸。→ Task 3 的防線只擋版本；tkinter 缺失的訊息留在 `ui.py` 現有的 ImportError 路徑，不另外處理。

import importlib.util
import sys
from pathlib import Path

import pytest

from core.text import T


def load_main():
    spec = importlib.util.spec_from_file_location("iplot_main", Path(__file__).resolve().parent.parent / "main.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def test_old_python_exits_with_message(monkeypatch):
    main = load_main()
    monkeypatch.setattr(sys, "version_info", (3, 9, 6, "final", 0))
    with pytest.raises(SystemExit) as ei:
        main.main()
    assert "3.10" in str(ei.value) and "3.9.6" in str(ei.value)


def test_need_python_text_in_t():
    assert "{found}" in T["need_python"]
