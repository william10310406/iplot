# Changelog

「Lean」這個模組的版本紀錄，格式跟 iPLoT 的 CHANGELOG.md 一樣（[Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)）。`tools/publish.py` 取最上面那一節的版本號當工作坊裡的版本，取那一節的第一段當清單頁上的「這一版」。

## [0.1.0] - 2026-11-10

第一版：按下去打開「Lean 實數遊戲」——只用 Lean，從自然數一路蓋到實數，再證不等式與極限（遊戲內容是英文）。遊戲跑在 adam.math.hhu.de 的公開伺服器上，需要網路、不用安裝；網頁面板上可以選在 iPLoT 的視窗裡玩或用瀏覽器玩，安全模式與後備面板直接用瀏覽器開。

### 新增
- 按下去先在訊息區說一兩句這是什麼、需要網路、不用安裝，再試著連 adam.math.hhu.de（8 秒逾時）；連不上就說一句原因、不開任何東西，不丟錯誤。
- 網頁面板：用 `app.page` 開一頁，兩顆鈕——「在這個視窗裡玩」把這個視窗換成遊戲，「用瀏覽器玩」交給系統的瀏覽器。那一頁本身不載入外部資源，遊戲的網址只是按鈕要去的地方；`api` 只攤出 `shown`、`browser` 兩個方法，不碰 `app`。
- 在 iPLoT 的視窗裡玩的限制寫在那一頁上：iPLoT 的頁面視窗不留網站資料（pywebview 的 private mode），關掉視窗進度就不見；視窗開著的時候模組還在執行，其他格要排隊。要留著進度就用瀏覽器。
- 安全模式與後備的 tkinter 面板沒有頁面：說一句之後直接用瀏覽器開；瀏覽器打不開時把網址寫在訊息區給人複製。
- 遊戲的原始碼在 https://github.com/william10310406/reals-game。
