# Changelog

「主控面板」這個模組的版本紀錄，格式跟 iPLoT 的 CHANGELOG.md 一樣（[Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)）。`tools/publish.py` 取最上面那一節的版本號當工作坊裡的版本，取那一節的第一段當清單頁上的「這一版」。

## [Unreleased]

## [0.2.0] - 2026-11-24

網頁面板本身搬進這個模組：面板的程式、畫面、選單都在這個資料夾裡，iPLoT 開機時找提供 `main` 的模組來開面板。要 iPLoT 0.9。

### 變更
- 面板（原本的 `ui/web.py`、`ui/index.html`、`ui/app.js`、`ui/style.css`）搬來這裡，宣告 `PROVIDES = {"main": "start"}`；只用核心公開的方法，不 import iPLoT 的內部。
- 錯誤旁邊的「回報這個問題」與自動問「要回報嗎？」改問提供 `panel.error` 的模組，不再寫死「回報與討論」。
- 拿掉面板裡的「頁面」（`app.page`）：頁面由「頁面」模組在另開的程序裡開。

## [0.1.4] - 2026-11-24

在 iPLoT 0.9 的面板上按「主控面板」，會說「主控面板已經開著」。以前在每按一次另開程序的 iPLoT 上會說「已經開著，但沒辦法把它叫到最前面」。

## [0.1.3] - 2026-11-23

在面板外按「主控面板」另開面板時，會確認面板真的起來了；一開就結束了會說「打不開主控面板：它一開就結束了」，原因記在 iPLoT 資料夾的 logs/separate.log。以前只說「打開主控面板」。

### 變更
- 另開的程序的錯誤輸出接到 `logs/separate.log`，不再丟掉（D160 第 3 條）。

## [0.1.2] - 2026-11-15

### 修正
- 打不開主控面板時，原因是中文並說怎麼辦；叫不到最前面時說到 Dock 點一下 Python 的圖示。

## [0.1.1] - 2026-11-06

加上 LICENSE（MIT）。

## [0.1.0] - 2026-10-07

第一版：打開 iPLoT 的面板；已經開著就叫到最前面。任何模組寫 `app.run("主控面板")` 就會用到這裡；在面板外（「互通」的捷徑、指令）也一樣。叫到最前面只在 macOS；別的系統一律開一個新的面板。
