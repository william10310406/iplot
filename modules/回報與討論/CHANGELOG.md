# Changelog

「回報與討論」這個模組的版本紀錄，格式跟 iPLoT 的 CHANGELOG.md 一樣（[Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)）。`tools/publish.py` 取最上面那一節的版本號當工作坊裡的版本，取那一節的第一段當清單頁上的「這一版」。

## [0.1.0] - 2026-10-25

iPLoT 出錯時，錯誤訊息旁邊的「回報這個問題」會整理好版本與錯誤、先把家目錄、使用者名稱、路徑、學號遮掉給你看，再用瀏覽器開到 iPLoT 的 GitHub 討論區；面板上這一格可以回報問題、提建議、問問題、看論壇。不登入、不存密碼，送出在瀏覽器裡按。錯誤訊息旁邊那顆鈕要 iPLoT 0.6.0；在 0.5.x 上只有這一格的四個入口。

### 新增
- 回報這個問題（`on_error`，D110、D112、D113）：整理 iPLoT 的版本、作業系統、Python、出錯的模組與版本、traceback，在預覽頁給你看、讓你改，再用預填的網址開瀏覽器到「問題回報」分類；開瀏覽器之前一律先把遮過的全文存進 `回報/`、複製到剪貼簿，GitHub 出錯或內容被截斷時直接貼上。tkinter 面板沒有預覽頁，改成用編輯器打開草稿。
- 遮蔽（`redact.py`，D111）：家目錄、使用者名稱、路徑、疑似學號、下一層模組的名稱（例如學生的資料夾）都遮掉；給人看之前遮一次、按「在瀏覽器打開」時再遮一次，預覽頁上方說遮了幾個。
- 四個入口（雙擊這一格，D114）：回報問題、提建議、問問題、看論壇；論壇的網址與分類只寫在 `forum.py`（D115）。整個模組不連網，只組網址交給瀏覽器。
